# Java 基础边界实验

本实验对应 [[基础]]、[[泛型与类型擦除]]、[[对象相等与不可变性]]、[[异常与资源管理]]、[[注解与反射]]、[[时间与金额处理]]。只使用 Java 标准库和 Python 标准库，无网络、数据库或第三方依赖。

在仓库根目录执行：

```sh
python3 '01-Java基础与并发/Java基础/实验/verify.py'
```

需要 PATH 中存在 Python 3、java 和 javac，JDK 至少为 17。脚本以 `--release 17` 编译 JavaBasicsLab.java，启用 `-Xlint:all -Werror`；故意制造 raw type 污染的局部方法显式抑制警告，其他代码仍接受检查。断言由 check/expect 执行，不依赖 `-ea`。

编译产物和故意不能编译的源码写入独立临时目录，结束时仅清理该临时目录。四个编译拒绝用例分别覆盖泛型不变性、擦除后方法签名冲突、参数化类型数组创建，以及对 extends 通配符写入具体数值。

## 验证对象

| 专题 | 主要断言 |
| --- | --- |
| 基础 | 重载与重写的两阶段选择、引用副本、字符串不变与实例复用 |
| 泛型 | 合法复制、擦除、堆污染、数组存储检查、桥接方法 |
| 相等与不可变 | 租户键、可变键失联、视图与复制、共享可变元素 |
| 资源 | 反向关闭、初始化失败、主体异常与 suppressed |
| 反射 | 注解保留策略、继承方法查找、业务异常包装 |
| 时间与金额 | 精度、舍入、集合比较、截止边界、夏令时缺口与重叠 |
