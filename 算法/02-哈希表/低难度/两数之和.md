# 两数之和

类型：[[算法/02-哈希表/哈希表详解|哈希表]] · 难度：低难度 · LeetCode 1（Easy / 简单）

题目来源：[LeetCode 1：两数之和](https://leetcode.com/problems/two-sum/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

在数组中找两个不同下标，使对应值之和等于 target。题目保证存在唯一答案。

示例：`nums=[4, 1, 6], target=7 → [1, 2]`。

## 从直觉到算法

暴力对每个元素扫描其后缀为 O(n²)。哈希表存已见元素，当前值 x 只需查 target-x。若存在，两个下标必然不同，因为当前下标还没放入表。

## 关键步骤推演

4 没有补数 3；1 没有补数 6；6 找到已保存的 1，返回其下标 1 与当前下标 2。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> seen = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            long complement = (long) target - nums[i];
            if (complement >= Integer.MIN_VALUE && complement <= Integer.MAX_VALUE) {
                Integer previous = seen.get((int) complement);
                if (previous != null) return new int[]{previous, i};
            }
            seen.put(nums[i], i);
        }
        throw new IllegalArgumentException("不存在满足条件的数对");
    }
}
```

## 复杂度与输入影响

平均时间 O(n)，空间 O(n)。返回下标，不修改输入。

## 边界用例与验证

[3,3]、目标 6 必须正确匹配两个位置。补数用 long 计算并检查 int 范围，避免溢出导致误匹配。无解时本实现抛异常，属于显式扩展契约。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
check(Arrays.equals(s.twoSum(new int[]{4,1,6},7),new int[]{1,2}));
check(Arrays.equals(s.twoSum(new int[]{3,3},6),new int[]{0,1}));
check(Arrays.equals(s.twoSum(new int[]{-3,4,3},0),new int[]{0,2}));
```

## 面试追问与变式

若返回所有数对，需决定按值去重还是按索引枚举；若输入有序，双指针可减少空间。
