# 字母异位词分组

类型：[[算法/02-哈希表/哈希表详解|哈希表]] · 难度：中等难度 · LeetCode 49（Medium / 中等）

题目来源：[LeetCode 49：字母异位词分组](https://leetcode.com/problems/group-anagrams/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

将仅含小写英文字母的字符串按异位词分组：同组字符串各字母出现次数相同。组与组内顺序不限。

示例：`["ab", "ba", "a", ""] → [["ab", "ba"], ["a"], [""]]`。

## 从直觉到算法

把每个词排序也能得到统一签名，但每词要 O(k log k)。对于固定 26 个字母，直接计数并生成带分隔符的签名；计数相等当且仅当两词互为异位词。

## 关键步骤推演

ab 与 ba 都生成 a:1、b:1、其余为零的计数，因此落入同一桶；a 的 b 次数为零，形成另一桶；空串对应全零签名。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public List<List<String>> groupAnagrams(String[] words) {
        Map<String, List<String>> groups = new HashMap<>();
        for (String word : words) {
            int[] count = new int[26];
            for (int i = 0; i < word.length(); i++) count[word.charAt(i) - 'a']++;
            StringBuilder key = new StringBuilder();
            for (int value : count) key.append('#').append(value);
            groups.computeIfAbsent(key.toString(), ignored -> new ArrayList<>()).add(word);
        }
        return new ArrayList<>(groups.values());
    }
}
```

## 复杂度与输入影响

设 N 为单词数、L 为总字符数，时间 O(L+26N)，存储签名和分组引用约 O(26N+N)，不复制原字符串内容。

## 边界用例与验证

本实现只处理 a-z；Unicode 需要明确按码点还是用户感知字符统计。空字符串也是有效词。结果顺序不稳定，测试应比较集合内容。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
List<List<String>> r=s.groupAnagrams(new String[]{"ab","ba","a",""});
check(r.size()==3); check(r.contains(Arrays.asList("ab","ba"))); check(r.contains(Arrays.asList("")));
check(s.groupAnagrams(new String[0]).isEmpty());
check(s.groupAnagrams(new String[]{"a","a"}).get(0).size()==2);
```
