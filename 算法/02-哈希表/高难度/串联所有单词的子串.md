# 串联所有单词的子串

类型：[[算法/02-哈希表/哈希表详解|哈希表]] · 难度：高难度 · LeetCode 30（Hard / 困难）

题目来源：[LeetCode 30：串联所有单词的子串](https://leetcode.com/problems/substring-with-concatenation-of-all-words/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

words 中所有单词长度相同且非空。找出 s 中恰好由所有单词按任意顺序连接成的子串起点，重复单词必须按次数匹配。

示例：`s="barfoofoo", words=["foo","bar"] → [0]`。

## 从直觉到算法

按单词长度 w 把起点分为 w 组，每组以 w 为步长滑动。窗口只包含词典内的单词，且每词次数不超过需要次数；一旦单词数量达到 words.length，就构成合法串联。

## 关键步骤推演

偏移 0：读 bar、foo 后计数满足要求，记录 0；继续读 foo 时超额，从左依次移走 bar 和旧 foo，剩一个 foo，不再满足总数。其他偏移遇到非词典片段时清空。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public List<Integer> findSubstring(String s, String[] words) {
        List<Integer> result = new ArrayList<>();
        if (words.length == 0 || words[0].isEmpty()) return result;
        int width = words[0].length();
        if ((long) width * words.length > s.length()) return result;
        Map<String, Integer> need = new HashMap<>();
        for (String word : words) need.merge(word, 1, Integer::sum);
        for (int offset = 0; offset < width; offset++) {
            int left = offset, count = 0;
            Map<String, Integer> window = new HashMap<>();
            for (int right = offset; right + width <= s.length(); right += width) {
                String word = s.substring(right, right + width);
                if (!need.containsKey(word)) {
                    window.clear(); count = 0; left = right + width;
                    continue;
                }
                window.merge(word, 1, Integer::sum); count++;
                while (window.get(word) > need.get(word)) {
                    String removed = s.substring(left, left + width);
                    window.put(removed, window.get(removed) - 1);
                    left += width; count--;
                }
                if (count == words.length) result.add(left);
            }
        }
        return result;
    }
}
```

## 复杂度与输入影响

设字符串长度 n、单词长度 w、词数 m。窗口步数 O(n)，但 Java substring 与哈希计算需 O(w)，总时间约 O((n+m)w)，Map 的词片段存储最坏 O(mw)，另加输出。

## 边界用例与验证

必须用次数而不是 Set；不同偏移要分别初始化。遇到未知单词须重置窗口。输出起点顺序不限；本实现不额外排序。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。
