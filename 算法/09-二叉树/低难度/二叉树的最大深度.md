# 二叉树的最大深度

类型：[[算法/09-二叉树/二叉树详解|二叉树]] · 难度：低难度 · LeetCode 104（Easy / 简单）

题目来源：[LeetCode 104：二叉树的最大深度](https://leetcode.com/problems/maximum-depth-of-binary-tree/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

返回根到最远叶子路径上的节点数，空树深度为零。

示例：`根 1，孩子 2、3 → 2`。

## 从直觉到算法

以当前节点为根的深度等于较深子树的深度加一。两棵子树的问题与原问题相同，空树返回零使叶节点自然得到一。

## 关键步骤推演

节点 2、3 的左右都为空，因此各返回 1；根收到两个 1，返回 2。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    static class TreeNode {
        int val;
        TreeNode left, right;
        TreeNode(int val) { this.val = val; }
    }

    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
    }
}
```

## 复杂度与输入影响

时间 O(n)，递归栈 O(h)，h 为树高。

## 边界用例与验证

不要把节点数与边数混淆。极深链状树建议改为迭代 DFS 或 BFS。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
TreeNode r=new TreeNode(1);r.left=new TreeNode(2);r.right=new TreeNode(3);check(s.maxDepth(r)==2);
check(s.maxDepth(null)==0);check(s.maxDepth(r.left)==1);
```
