# 二叉树的层序遍历

类型：[[算法/09-二叉树/二叉树详解|二叉树]] · 难度：中等难度 · LeetCode 102（Medium / 中等）

题目来源：[LeetCode 102：二叉树的层序遍历](https://leetcode.com/problems/binary-tree-level-order-traversal/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

按从上到下、每层从左到右返回节点值列表。

示例：`根 1，孩子 2、3；2 的左孩子为 4 → [[1],[2,3],[4]]`。

## 从直觉到算法

队列先进先出，父节点处理后把左右孩子放到队尾。每轮先记录当前队列大小，只处理这个数量，避免把本轮新增的下一层节点也混入当前层。

## 关键步骤推演

首轮 size=1 取根并加入 2、3；第二轮 size=2，依次取 2、3 并加入 4；第三轮只取 4。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    static class TreeNode {
        int val;
        TreeNode left, right;
        TreeNode(int val) { this.val = val; }
    }

    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;
        Deque<TreeNode> queue = new ArrayDeque<>(); queue.addLast(root);
        while (!queue.isEmpty()) {
            int size = queue.size();
            List<Integer> level = new ArrayList<>();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.removeFirst(); level.add(node.val);
                if (node.left != null) queue.addLast(node.left);
                if (node.right != null) queue.addLast(node.right);
            }
            result.add(level);
        }
        return result;
    }
}
```

## 复杂度与输入影响

时间 O(n)，队列额外空间 O(w)，w 为最大层宽，结果 O(n)。

## 边界用例与验证

空树直接返回空列表；ArrayDeque 不允许加入 null，所以仅加入存在的孩子。不能用循环中不断变化的 queue.size() 作为本层边界。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
TreeNode r=new TreeNode(1);r.left=new TreeNode(2);r.right=new TreeNode(3);r.left.left=new TreeNode(4);
check(s.levelOrder(r).equals(Arrays.asList(Arrays.asList(1),Arrays.asList(2,3),Arrays.asList(4))));check(s.levelOrder(null).isEmpty());
```
