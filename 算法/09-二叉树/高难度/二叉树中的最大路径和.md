# 二叉树中的最大路径和

类型：[[算法/09-二叉树/二叉树详解|二叉树]] · 难度：高难度 · LeetCode 124（Hard / 困难）

题目来源：[LeetCode 124：二叉树中的最大路径和](https://leetcode.com/problems/binary-tree-maximum-path-sum/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

在非空二叉树中找节点不重复的非空路径，使节点值总和最大；路径不必经过根。

示例：`根 -10，左 9，右 20，20 的孩子为 15、7 → 42`。

## 从直觉到算法

递归返回当前节点向父节点能提供的最大单支贡献，负贡献舍弃。当前节点作为最高点时，左右正贡献都可相加更新全局答案；但返回给父节点只能选一个方向，否则会产生分叉，不再是路径。

## 关键步骤推演

15、7 各贡献自身；20 连接两侧得到 42，但只向上返回 35；根连接 9 与 35 得 34，因此最终答案仍为 42。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    static class TreeNode {
        int val;
        TreeNode left, right;
        TreeNode(int val) { this.val = val; }
    }

    public long maxPathSum(TreeNode root) {
        if (root == null) throw new IllegalArgumentException("树必须非空");
        long[] best = {Long.MIN_VALUE};
        gain(root, best);
        return best[0];
    }
    private long gain(TreeNode node, long[] best) {
        if (node == null) return 0;
        long left = Math.max(0, gain(node.left, best));
        long right = Math.max(0, gain(node.right, best));
        best[0] = Math.max(best[0], node.val + left + right);
        return node.val + Math.max(left, right);
    }
}
```

## 复杂度与输入影响

时间 O(n)，递归栈 O(h)。累计与答案用 long，避免节点和溢出。

## 边界用例与验证

全负数必须取最大单节点，答案初始化 Long.MIN_VALUE。每次公开调用都重新初始化状态，避免复用 Solution 时遗留结果。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
TreeNode r=new TreeNode(-10);r.left=new TreeNode(9);r.right=new TreeNode(20);r.right.left=new TreeNode(15);r.right.right=new TreeNode(7);
check(s.maxPathSum(r)==42);check(s.maxPathSum(new TreeNode(-3))==-3);

```
