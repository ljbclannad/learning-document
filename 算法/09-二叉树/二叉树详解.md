# 二叉树详解

返回 [[算法/算法学习导航]]。

## 核心思想与识别信号

二叉树每个节点最多有左右两个孩子。递归题要明确函数返回的是“当前子树的什么信息”，层序题要明确队列里保存的是哪一层的待处理节点。普通二叉树不具备二叉搜索树的大小顺序。

## 执行机制与正确性依据

深度优先把问题交给左右子树，再合并它们的返回值，空节点是递归基线。广度优先使用队列，每轮先固定队列长度，就能精确取出一层。路径和题还要区分可向父节点延伸的单支结果，与在当前节点连接左右两支的完整候选。

## 手动推演

树根 1，左子 2，右子 3：最大深度是 1+max(1,1)=2；层序先取 [1] 再取 [2,3]；最大路径和可连接 2→1→3 得 6，但向根的父节点返回时只能选一支，不能把两支一起延伸。

## Java 入门模板

以下为本类型低难度代表题的完整实现，可作为理解状态与更新顺序的起点；它不是所有变式的通用答案。先说清状态含义，再修改模板。代码基线为 Java 17。

```java
class Solution {
    static class TreeNode {
        int val;
        TreeNode left, right;
        TreeNode(int val) { this.val = val; }
    }

    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
    }
}
```

模板复杂度：时间 O(n)，递归栈 O(h)，h 为树高。

## 适用边界与常见错误

递归空间按高度 h 计算，平衡树是 O(log n)，链状树是 O(n)，Java 深递归可能栈溢出。全负数最大路径不能初始化为零。输入若有环或共享子节点，就不再是这些算法假定的普通树。

## 工程联系

组织结构、表达式树等可用树遍历，但组织变更和权限继承有业务规则，不能仅靠遍历推断授权语义。深层目录遍历可改用显式栈避免递归栈限制。
