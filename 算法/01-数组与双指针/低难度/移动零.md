# 移动零

类型：[[算法/01-数组与双指针/数组与双指针详解|数组与双指针]] · 难度：低难度 · LeetCode 283（Easy / 简单）

题目来源：[LeetCode 283：移动零](https://leetcode.com/problems/move-zeroes/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

给定整数数组，把所有零移到末尾，保持非零元素相对顺序，原地修改数组。

示例：`[0, 4, 0, 2] → [4, 2, 0, 0]`。

## 从直觉到算法

逐次删除并移动后续元素会达到 O(n²)。改为先把非零元素按出现顺序写到前缀，再把剩余区域填零；已写入部分就是正确结果。

## 关键步骤推演

读到 0 跳过；读到 4 写入 nums[0]，write=1；第二个 0 跳过；读到 2 写入 nums[1]，write=2；最后位置 2、3 补零。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int write = 0;
        for (int read = 0; read < nums.length; read++) {
            if (nums[read] != 0) nums[write++] = nums[read];
        }
        while (write < nums.length) nums[write++] = 0;
    }
}
```

## 复杂度与输入影响

时间 O(n)，额外空间 O(1)。修改输入，保持非零元素的稳定顺序。

## 边界用例与验证

不能一边遍历一边用零覆盖未读区域。空数组、全零和没有零均应成立。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
int[] a={0,4,0,2}; s.moveZeroes(a); check(Arrays.equals(a,new int[]{4,2,0,0}));
int[] b={0,0}; s.moveZeroes(b); check(Arrays.equals(b,new int[]{0,0}));
int[] c={1,2}; s.moveZeroes(c); check(Arrays.equals(c,new int[]{1,2}));
s.moveZeroes(new int[0]);
```

## 面试追问与变式

若要求尽量少写内存，可以在 read != write 时才搬移；若还要求保留零元素的额外属性，则需重新定义稳定性。
