# 数组与双指针详解

返回 [[算法/算法学习导航]]。

## 核心思想与识别信号

数组用下标直接访问元素。双指针在数组上维护两个有不同职责的位置，利用有序性或已处理区间，避免重复扫描。它不是所有双重循环的替代品：每次移动必须能证明不会漏解。

## 执行机制与正确性依据

快慢指针用于原地筛选：读指针遍历输入，写指针标记下一处有效输出，始终保持 [0, write) 是已处理部分的正确结果。相向指针适用于排序后的配对：和太小就移动左端，和太大就移动右端，因为对应方向的其他候选也不可能满足目标。两种模式的不变量不同，不能混用移动规则。

## 手动推演

将 [0, 4, 0, 2] 的非零元素前移：write 从 0 开始，读到 4 写入位置 0，读到 2 写入位置 1；剩余两格补零，得到 [4, 2, 0, 0]。write 从不超过 read，因此不会覆盖尚未读取的元素。

## Java 入门模板

以下为本类型低难度代表题的完整实现，可作为理解状态与更新顺序的起点；它不是所有变式的通用答案。先说清状态含义，再修改模板。代码基线为 Java 17。

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int write = 0;
        for (int read = 0; read < nums.length; read++) {
            if (nums[read] != 0) nums[write++] = nums[read];
        }
        while (write < nums.length) nums[write++] = 0;
    }
}
```

模板复杂度：时间 O(n)，额外空间 O(1)。修改输入，保持非零元素的稳定顺序。

## 适用边界与常见错误

排序会改变原位置，需要原始下标时应保存索引。求和先提升为 long，避免 int 溢出使方向判断反转。三数之和要按值去重；两数之和返回索引则不能直接跳过相同值。接雨水还依赖左右边界最大值，不能只比较相邻柱子。

## 工程联系

接口返回结果去除无效项可类比快慢指针；批量数据合并可类比相向或同向扫描。这些只是数据处理方法，不能据此声称接口整体复杂度为 O(n)，还需计算数据库和网络成本。
