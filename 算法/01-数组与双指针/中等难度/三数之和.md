# 三数之和

类型：[[算法/01-数组与双指针/数组与双指针详解|数组与双指针]] · 难度：中等难度 · LeetCode 15（Medium / 中等）

题目来源：[LeetCode 15：三数之和](https://leetcode.com/problems/3sum/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

返回数组中和为零的所有不重复三元组；三个元素必须来自不同下标，结果顺序不限。

示例：`[-2, 0, 0, 2, 2] → [[-2, 0, 2]]`。

## 从直觉到算法

暴力枚举三个下标为 O(n³)。排序后固定第一个数，在剩余区间用左右指针找其相反数。和偏小只能增大左端才有机会，和偏大只能减小右端；因此一次扫描覆盖该固定数的所有候选。

## 关键步骤推演

固定 -2，左右值为 0 与 2，和为 0，记录；跳过相同的 0 和 2，避免再次记录相同三元组。下一个固定数为 0 时，剩余两数无法凑零。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> result = new ArrayList<>();
        for (int i = 0; i < nums.length - 2; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            int left = i + 1, right = nums.length - 1;
            while (left < right) {
                long sum = (long) nums[i] + nums[left] + nums[right];
                if (sum < 0) left++;
                else if (sum > 0) right--;
                else {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    int a = nums[left], b = nums[right];
                    while (left < right && nums[left] == a) left++;
                    while (left < right && nums[right] == b) right--;
                }
            }
        }
        return result;
    }
}
```

## 复杂度与输入影响

时间 O(n²)。结果空间最坏 O(n²)；除此之外指针空间 O(1)，排序实现还可能使用栈等辅助空间。会排序并修改输入。

## 边界用例与验证

三个零必须返回一个三元组；重复固定值和命中后的重复左右值都要跳过。先转 long 再相加。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
check(s.threeSum(new int[]{-2,0,0,2,2}).equals(Arrays.asList(Arrays.asList(-2,0,2))));
check(s.threeSum(new int[]{0,0,0,0}).size()==1);

```

## 面试追问与变式

推广为四数之和时，固定两层再用双指针；若要返回原下标，应保留原位置且重新定义去重规则。
