# 接雨水

类型：[[算法/01-数组与双指针/数组与双指针详解|数组与双指针]] · 难度：高难度 · LeetCode 42（Hard / 困难）

题目来源：[LeetCode 42：接雨水](https://leetcode.com/problems/trapping-rain-water/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

非负整数表示等宽柱子高度，计算下雨后可积存的总水量。

示例：`[3, 0, 2, 0, 4] → 7`。

## 从直觉到算法

每格水量为 min(左侧最高柱, 右侧最高柱) 减去当前高度。先预处理两个最大值数组可用 O(n) 空间。双指针维护已扫描两侧的最大值，每次结算最大值较小的一侧；另一侧已经有足够高的柱子，未见区域不会改变这一格的水位上限。

## 关键步骤推演

左右最大值先是 3、4，结算左侧；随后高度 0、2、0 分别贡献 3、1、3。左侧最大值始终为 3，右边已有高度 4，因此这些格子的水位都可确定。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    public long trap(int[] height) {
        int left = 0, right = height.length - 1;
        int leftMax = 0, rightMax = 0;
        long water = 0;
        while (left <= right) {
            leftMax = Math.max(leftMax, height[left]);
            rightMax = Math.max(rightMax, height[right]);
            if (leftMax <= rightMax) water += leftMax - height[left++];
            else water += rightMax - height[right--];
        }
        return water;
    }
}
```

## 复杂度与输入影响

时间 O(n)，额外空间 O(1)。返回 long 以容纳更大的教学输入，未修改输入。平台给定范围内可按要求转为 int。

## 边界用例与验证

高度必须非负。零根柱子、单根柱子、单调数组均积水为零。不能把较高的一侧提前结算，因为其另一侧真实最大值可能尚未出现。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
check(s.trap(new int[]{3,0,2,0,4})==7);
check(s.trap(new int[]{1,2,3})==0); check(s.trap(new int[0])==0);
check(s.trap(new int[]{5})==0); check(s.trap(new int[]{2,0,2})==2);
```
