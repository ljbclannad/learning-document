# 回溯详解

返回 [[算法/算法学习导航]]。

## 核心思想与识别信号

回溯显式探索选择树：做选择、递归、撤销选择。用于枚举排列、组合和满足约束的方案。它仍可能是指数或阶乘复杂度，剪枝只是提前排除不可能成功的分支，不会凭空消除输出本身的成本。

## 执行机制与正确性依据

先定义状态：路径 path、可选集合和终止条件。排列用 used 表示哪些位置已使用；组合用 start 限制只能向后选，避免相同组合的不同顺序。递归返回时撤销本层变更，保证兄弟分支看到同一个父状态。保存结果时必须复制路径。

## 手动推演

排列 [1,2]：先选 1，再选 2，复制 [1,2]；撤销 2，再撤销 1；改选 2，再选 1，复制 [2,1]。若直接保存 path 引用，两条结果最终都会随 path 清空。

## Java 入门模板

以下为本类型低难度代表题的完整实现，可作为理解状态与更新顺序的起点；它不是所有变式的通用答案。先说清状态含义，再修改模板。代码基线为 Java 17。

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> readBinaryWatch(int turnedOn) {
        List<String> result = new ArrayList<>();
        if (turnedOn < 0 || turnedOn > 10) return result;
        choose(0, turnedOn, 0, 0, result);
        return result;
    }
    private void choose(int start, int remaining, int hour, int minute, List<String> result) {
        if (hour >= 12 || minute >= 60 || 10 - start < remaining) return;
        if (remaining == 0) {
            result.add(hour + ":" + (minute < 10 ? "0" : "") + minute);
            return;
        }
        for (int i = start; i < 10; i++) {
            if (i < 4) choose(i + 1, remaining - 1, hour + (1 << i), minute, result);
            else choose(i + 1, remaining - 1, hour, minute + (1 << (i - 4)), result);
        }
    }
}
```

模板复杂度：灯数固定为 10，搜索空间有界；若推广为 B 个灯，组合搜索节点不超过 O(2^B)，递归深度 O(B)，输出另计。

## 适用边界与常见错误

剪枝要有证据，例如剩余候选数不足所需数量，或 N 皇后列与对角线冲突。重复元素需要同层去重，不能简单用一个全局 Set 禁止相同值。递归与全局可变状态结合时，要防止多次调用污染结果。

## 工程联系

小规模约束组合和配置枚举可使用回溯。真实排班等问题规模很大时，通常要约束求解或启发式方法；不能把 N 皇后模板当作生产求解器。
