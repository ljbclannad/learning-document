# 二进制手表

类型：[[算法/11-回溯/回溯详解|回溯]] · 难度：低难度 · LeetCode 401（Easy / 简单）

题目来源：[LeetCode 401：二进制手表](https://leetcode.com/problems/binary-watch/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

4 个灯表示小时 0～11，6 个灯表示分钟 0～59，返回恰好亮 turnedOn 个灯的全部合法时间。小时不补零，分钟补足两位。

示例：`turnedOn=0 → ["0:00"]；turnedOn=1 共 10 种时间`。

## 从直觉到算法

把 10 个灯看成候选位置，从小到大选择若干灯，累加小时和分钟。用 start 保证每个灯组合只被选一次；小时或分钟越界后立即剪枝，因为后续只会继续增加。

## 关键步骤推演

选择小时灯权值 1 后，时间为 1:00；选择分钟灯权值 1 后，时间为 0:01。位置不同即不同选择，不能把相同权值的小时灯与分钟灯混为一类。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> readBinaryWatch(int turnedOn) {
        List<String> result = new ArrayList<>();
        if (turnedOn < 0 || turnedOn > 10) return result;
        choose(0, turnedOn, 0, 0, result);
        return result;
    }
    private void choose(int start, int remaining, int hour, int minute, List<String> result) {
        if (hour >= 12 || minute >= 60 || 10 - start < remaining) return;
        if (remaining == 0) {
            result.add(hour + ":" + (minute < 10 ? "0" : "") + minute);
            return;
        }
        for (int i = start; i < 10; i++) {
            if (i < 4) choose(i + 1, remaining - 1, hour + (1 << i), minute, result);
            else choose(i + 1, remaining - 1, hour, minute + (1 << (i - 4)), result);
        }
    }
}
```

## 复杂度与输入影响

灯数固定为 10，搜索空间有界；若推广为 B 个灯，组合搜索节点不超过 O(2^B)，递归深度 O(B)，输出另计。
