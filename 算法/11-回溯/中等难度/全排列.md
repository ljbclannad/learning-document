# 全排列

类型：[[算法/11-回溯/回溯详解|回溯]] · 难度：中等难度 · LeetCode 46（Medium / 中等）

题目来源：[LeetCode 46：全排列](https://leetcode.com/problems/permutations/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

给定互不相同的整数，返回所有排列，结果顺序不限。

示例：`[1,2] → [[1,2],[2,1]]`。

## 从直觉到算法

每一层选择下一个位置的值。used 标记原数组下标是否已经在当前路径中，path 长度达到 n 时复制为一个完整排列。返回父层时同时撤销 path 和 used。

## 关键步骤推演

从根先选 1，再选 2 得 [1,2]，撤销两层后先选 2，再选 1 得 [2,1]。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> permute(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        search(nums, new boolean[nums.length], new ArrayList<>(), result);
        return result;
    }
    private void search(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> result) {
        if (path.size() == nums.length) { result.add(new ArrayList<>(path)); return; }
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            used[i] = true; path.add(nums[i]);
            search(nums, used, path, result);
            path.remove(path.size() - 1); used[i] = false;
        }
    }
}
```

## 复杂度与输入影响

共有 n! 个结果，复制每条长度 n 的路径，时间 O(n·n!)；工作空间 O(n)，结果空间 O(n·n!)。
