# 反转链表

类型：[[算法/05-链表/链表详解|链表]] · 难度：低难度 · LeetCode 206（Easy / 简单）

题目来源：[LeetCode 206：反转链表](https://leetcode.com/problems/reverse-linked-list/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

反转无环单链表，返回新头节点。复用原节点。

示例：`1→2→3→null → 3→2→1→null`。

## 从直觉到算法

维护已反转前缀 prev 和未处理后缀 current，每次将 current 移到前缀头部。保存 next 后再改边，能保证原后缀仍可继续访问。

## 关键步骤推演

初始 prev=null；处理 1 后 prev=1；处理 2 后 prev=2→1；处理 3 后 prev=3→2→1，current=null 结束。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    static class ListNode {
        int val;
        ListNode next;
        ListNode(int val) { this.val = val; }
    }

    public ListNode reverseList(ListNode head) {
        ListNode prev = null, current = head;
        while (current != null) {
            ListNode next = current.next;
            current.next = prev;
            prev = current;
            current = next;
        }
        return prev;
    }
}
```

## 复杂度与输入影响

时间 O(n)，额外空间 O(1)。原链表引用结构被修改。

## 边界用例与验证

若先写 current.next=prev 再读取 next，会丢失后缀。空链返回 null，单节点仍需保持 next=null。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
ListNode a=new ListNode(1),b=new ListNode(2),c=new ListNode(3); a.next=b; b.next=c;
check(s.reverseList(a)==c); check(c.next==b && b.next==a && a.next==null);
check(s.reverseList(null)==null); check(s.reverseList(a)==a);
```
