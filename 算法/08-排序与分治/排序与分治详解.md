# 排序与分治详解

返回 [[算法/算法学习导航]]。

## 核心思想与识别信号

分治把问题拆成规模更小的同类问题，独立解决后合并。排序不仅产生有序数据，也能暴露原来难以判断的相对关系；归并过程可以同时统计逆序对、右侧更小数量等。

## 执行机制与正确性依据

归并排序先把区间拆成两半，各自有序后，用两个指针线性合并。每层所有区间合计 O(n) 工作，层数 O(log n)，所以总时间 O(n log n)。需要额外缓冲数组；当左右相等时先取左边，可维持稳定性。

## 手动推演

[4,1,3,2] 拆为 [4,1] 与 [3,2]，分别排成 [1,4] 和 [2,3]，合并依次选 1、2、3、4。统计右侧更小时，还需记录每个元素的原下标，不能排序后丢失身份。

## Java 入门模板

以下为本类型低难度代表题的完整实现，可作为理解状态与更新顺序的起点；它不是所有变式的通用答案。先说清状态含义，再修改模板。代码基线为 Java 17。

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int i = m - 1, j = n - 1, write = m + n - 1;
        while (j >= 0) {
            if (i >= 0 && nums1[i] > nums2[j]) nums1[write--] = nums1[i--];
            else nums1[write--] = nums2[j--];
        }
    }
}
```

模板复杂度：时间 O(m+n)，额外空间 O(1)，修改 nums1。

## 适用边界与常见错误

递归必须有严格缩小的区间与长度小于 2 的出口。快速排序平均 O(n log n)，极端分区可能 O(n²)；不能把归并排序的最坏界套给所有排序。比较器用 Integer.compare，减法比较可能溢出。

## 工程联系

多份有序数据合并、离线统计适合归并思路。超内存数据需要外部归并，还要计算磁盘 I/O；内存中的时间复杂度并不涵盖这些成本。
