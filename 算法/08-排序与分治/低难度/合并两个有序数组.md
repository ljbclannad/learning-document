# 合并两个有序数组

类型：[[算法/08-排序与分治/排序与分治详解|排序与分治]] · 难度：低难度 · LeetCode 88（Easy / 简单）

题目来源：[LeetCode 88：合并两个有序数组](https://leetcode.com/problems/merge-sorted-array/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

nums1 前 m 项和 nums2 前 n 项分别升序，nums1 总容量为 m+n，将二者合并到 nums1。

示例：`nums1=[1,4,0,0], m=2；nums2=[2,3], n=2 → [1,2,3,4]`。

## 从直觉到算法

从头写 nums1 会覆盖还未读取的值。从尾部选择较大值写到末尾，写入位置始终不会破坏 nums1 未处理前缀。

## 关键步骤推演

先比较 4 和 3，把 4 放到最后；再放 3、2，最后 1 本来就在正确位置。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int i = m - 1, j = n - 1, write = m + n - 1;
        while (j >= 0) {
            if (i >= 0 && nums1[i] > nums2[j]) nums1[write--] = nums1[i--];
            else nums1[write--] = nums2[j--];
        }
    }
}
```

## 复杂度与输入影响

时间 O(m+n)，额外空间 O(1)，修改 nums1。

## 边界用例与验证

nums1 尾部零只是容量占位，不能按数值判断有效范围。nums2 处理完即可结束，nums1 剩余前缀无需搬移。
