# 计算右侧小于当前元素的个数

类型：[[算法/08-排序与分治/排序与分治详解|排序与分治]] · 难度：高难度 · LeetCode 315（Hard / 困难）

题目来源：[LeetCode 315：计算右侧小于当前元素的个数](https://leetcode.com/problems/count-of-smaller-numbers-after-self/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

对每个原始位置，计算其右边严格小于当前值的元素数量。

示例：`[5,2,6,1] → [2,1,1,0]`。

## 从直觉到算法

排序的是原始下标数组，并按对应值归并。左半某元素出队时，已经从右半移出的元素都严格小于它，且原位置在其右边，将已移出数量加到该元素答案。相等时先取左边，避免相等值计入。

## 关键步骤推演

先在 [5,2] 内给 5 加 1，在 [6,1] 内给 6 加 1；合并 [2,5] 与 [1,6] 时，1 先出队，随后 2 和 5 各再加 1，得到 [2,1,1,0]。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> countSmaller(int[] nums) {
        int n = nums.length;
        int[] index = new int[n], buffer = new int[n], count = new int[n];
        for (int i = 0; i < n; i++) index[i] = i;
        sort(nums, index, buffer, count, 0, n);
        List<Integer> result = new ArrayList<>();
        for (int value : count) result.add(value);
        return result;
    }
    private void sort(int[] nums, int[] index, int[] buffer, int[] count, int left, int right) {
        if (right - left < 2) return;
        int mid = left + (right - left) / 2;
        sort(nums, index, buffer, count, left, mid);
        sort(nums, index, buffer, count, mid, right);
        int i = left, j = mid, moved = 0;
        for (int k = left; k < right; k++) {
            if (j < right && (i == mid || nums[index[j]] < nums[index[i]])) {
                buffer[k] = index[j++]; moved++;
            } else {
                count[index[i]] += moved;
                buffer[k] = index[i++];
            }
        }
        System.arraycopy(buffer, left, index, left, right - left);
    }
}
```

## 复杂度与输入影响

时间 O(n log n)，索引、缓冲和答案共 O(n)，递归栈 O(log n)。不修改原数组。

## 边界用例与验证

排序后必须写回原下标对应的答案。严格小于要求等值时不增加计数。重复值和逆序数组最能暴露边界错误。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

