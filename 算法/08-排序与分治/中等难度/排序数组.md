# 排序数组

类型：[[算法/08-排序与分治/排序与分治详解|排序与分治]] · 难度：中等难度 · LeetCode 912（Medium / 中等）

题目来源：[LeetCode 912：排序数组](https://leetcode.com/problems/sort-an-array/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

将整数数组升序排列，不调用库排序函数，使用归并排序达到 O(n log n)。

示例：`[4,1,3,2] → [1,2,3,4]`。

## 从直觉到算法

递归处理半开区间 [left,right)，长度不足 2 时已经有序。两个有序子区间合并到共享缓冲，再复制回原区间；共享缓冲避免每次递归重新分配大数组。

## 关键步骤推演

左右两组分别变成 [1,4]、[2,3]；比较两个头部，依次写出 1、2、3，再补剩余 4。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    public int[] sortArray(int[] nums) {
        sort(nums, new int[nums.length], 0, nums.length);
        return nums;
    }
    private void sort(int[] nums, int[] buffer, int left, int right) {
        if (right - left < 2) return;
        int mid = left + (right - left) / 2;
        sort(nums, buffer, left, mid); sort(nums, buffer, mid, right);
        int i = left, j = mid;
        for (int k = left; k < right; k++) {
            if (j == right || (i < mid && nums[i] <= nums[j])) buffer[k] = nums[i++];
            else buffer[k] = nums[j++];
        }
        System.arraycopy(buffer, left, nums, left, right - left);
    }
}
```

## 复杂度与输入影响

时间 O(n log n)，缓冲空间 O(n)，递归栈 O(log n)。修改输入并返回同一数组。

## 边界用例与验证

判断右侧是否耗尽要在读取 nums[j] 之前；相等时先拿左边保持稳定。空数组直接返回。

## 面试追问与变式

若子区间已有 nums[mid-1]<=nums[mid]，可跳过合并；这影响最好情况，但不改变一般最坏界。
