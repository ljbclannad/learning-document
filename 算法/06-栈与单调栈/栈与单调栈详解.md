# 栈与单调栈详解

返回 [[算法/算法学习导航]]。

## 核心思想与识别信号

普通栈维护后进先出的待处理项，适合括号嵌套和表达式求值。单调栈额外要求元素按值单调排列，用弹栈时机确定“第一个更大或更小元素”的边界。

## 执行机制与正确性依据

有效括号保存期望的关闭符号，输入关闭符号时核对栈顶。每日温度保存未找到更高温度的下标，新温度更高时弹出并结算距离。柱状图维护非递减高度的下标，遇到更低柱子时，右侧更矮边界确定，弹栈后栈顶给出左侧边界。

## 手动推演

温度 [30,32,31,35]：32 到来时弹出 30，等待 1 天；35 到来时先弹 31、再弹 32，分别等待 1、2 天。每个下标最多进出栈一次，嵌套 while 不意味着 O(n²)。

## Java 入门模板

以下为本类型低难度代表题的完整实现，可作为理解状态与更新顺序的起点；它不是所有变式的通用答案。先说清状态含义，再修改模板。代码基线为 Java 17。

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch == '(') stack.push(')');
            else if (ch == '[') stack.push(']');
            else if (ch == '{') stack.push('}');
            else if (stack.isEmpty() || stack.pop() != ch) return false;
        }
        return stack.isEmpty();
    }
}
```

模板复杂度：时间 O(n)，空间 O(n)，最坏所有字符都是左括号。

## 适用边界与常见错误

需要位置或距离时保存下标，不能只保存值。相等元素是弹出还是保留取决于“严格更大”和边界归属；应通过重复值用例验证。Java 示例使用 ArrayDeque，不能向其插入 null。

## 工程联系

调用过程和括号解析天然具有嵌套关系；监控序列中“下一次超过阈值的位置”可借鉴单调栈。流式输入若要求立即给出所有答案，尚未遇到更大值的元素只能继续等待。
