# 每日温度

类型：[[算法/06-栈与单调栈/栈与单调栈详解|栈与单调栈]] · 难度：中等难度 · LeetCode 739（Medium / 中等）

题目来源：[LeetCode 739：每日温度](https://leetcode.com/problems/daily-temperatures/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

对每天温度，返回还需等待几天才会遇到严格更高温度；不存在则为零。

示例：`[30,32,31,35] → [1,2,1,0]`。

## 从直觉到算法

栈中保存尚未找到答案的日期下标，对应温度从栈底到栈顶非递增。新温度严格更高时，栈顶日期的第一个更高温度就是今天，弹出并记录距离。

## 关键步骤推演

下标 1 弹出 0 得 1；下标 2 入栈；下标 3 依次弹出 2 得 1、弹出 1 得 2。最后下标 3 没有更高温度，保留默认 0。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int[] answer = new int[temperatures.length];
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i < temperatures.length; i++) {
            while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
                int previous = stack.pop();
                answer[previous] = i - previous;
            }
            stack.push(i);
        }
        return answer;
    }
}
```

## 复杂度与输入影响

时间 O(n)，辅助栈 O(n)，结果数组 O(n)。

## 边界用例与验证

相等温度不是更高，比较必须是 >。记录 i-previous 而不是温度差。
