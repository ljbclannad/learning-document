# 有效的括号

类型：[[算法/06-栈与单调栈/栈与单调栈详解|栈与单调栈]] · 难度：低难度 · LeetCode 20（Easy / 简单）

题目来源：[LeetCode 20：有效的括号](https://leetcode.com/problems/valid-parentheses/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

字符串只包含 ()[]{}，判断每个括号是否按正确顺序成对闭合。

示例：`"([])" → true；"([)]" → false`。

## 从直觉到算法

最近打开的括号必须最先关闭，因此使用栈。遇到左括号压入对应右括号，遇到右括号时弹出一个期望值核对，扫描完后栈也必须为空。

## 关键步骤推演

处理 ( 压入 )，处理 [ 压入 ]；输入 ] 与栈顶一致，再输入 ) 一致，最后空栈，合法。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch == '(') stack.push(')');
            else if (ch == '[') stack.push(']');
            else if (ch == '{') stack.push('}');
            else if (stack.isEmpty() || stack.pop() != ch) return false;
        }
        return stack.isEmpty();
    }
}
```

## 复杂度与输入影响

时间 O(n)，空间 O(n)，最坏所有字符都是左括号。

## 边界用例与验证

栈空时不能直接 pop；结束时非空表示还有未闭合左括号。本文将空串视为合法扩展输入。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
check(s.isValid("([])"));check(!s.isValid("([)]"));check(!s.isValid("]"));check(!s.isValid("(("));check(s.isValid(""));
```
