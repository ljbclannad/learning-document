# 柱状图中最大的矩形

类型：[[算法/06-栈与单调栈/栈与单调栈详解|栈与单调栈]] · 难度：高难度 · LeetCode 84（Hard / 困难）

题目来源：[LeetCode 84：柱状图中最大的矩形](https://leetcode.com/problems/largest-rectangle-in-histogram/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

非负整数数组表示等宽柱子，求连续柱子中能容纳的最大矩形面积。

示例：`[2,1,5,6,2,3] → 10`。

## 从直觉到算法

每个高度作为矩形最矮柱时，需要找到左右不能再扩展的边界。维护高度非递减栈；出现更矮柱时弹出，当前 i 是右边界，弹出后的栈顶是左边界，宽度为 i-left-1。相等高度保留，较早的相等柱最终会覆盖完整宽度。

## 关键步骤推演

扫描到下标 4 的高度 2，先弹高度 6，宽度 1，面积 6；再弹高度 5，左界下标 1，宽度 4-1-1=2，面积 10。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public long largestRectangleArea(int[] heights) {
        Deque<Integer> stack = new ArrayDeque<>();
        long best = 0;
        for (int i = 0; i <= heights.length; i++) {
            int current = i == heights.length ? 0 : heights[i];
            while (!stack.isEmpty() && heights[stack.peek()] > current) {
                int height = heights[stack.pop()];
                int left = stack.isEmpty() ? -1 : stack.peek();
                best = Math.max(best, (long) height * (i - left - 1));
            }
            if (i < heights.length) stack.push(i);
        }
        return best;
    }
}
```

## 复杂度与输入影响

时间 O(n)，空间 O(n)。面积用 long，不修改输入。

## 边界用例与验证
