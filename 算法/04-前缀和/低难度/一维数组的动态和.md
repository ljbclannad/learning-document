# 一维数组的动态和

类型：[[算法/04-前缀和/前缀和详解|前缀和]] · 难度：低难度 · LeetCode 1480（Easy / 简单）

题目来源：[LeetCode 1480：一维数组的动态和](https://leetcode.com/problems/running-sum-of-1d-array/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

返回一个新数组，其第 i 项等于输入从下标 0 到 i 的累加和。

示例：`[2, -1, 3] → [2, 1, 4]`。

## 从直觉到算法

每个结果重复累加前缀需 O(n²)。相邻前缀仅新增当前元素，保留一个累计变量即可。

## 关键步骤推演

累计值从 0 开始，加入 2 得 2；加入 -1 得 1；加入 3 得 4，每一步写入对应位置。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    public long[] runningSum(int[] nums) {
        long[] result = new long[nums.length];
        long sum = 0;
        for (int i = 0; i < nums.length; i++) result[i] = sum += nums[i];
        return result;
    }
}
```

## 复杂度与输入影响

时间 O(n)，输出空间 O(n)，除输出外额外空间 O(1)。返回 long[]，这是为避免 int 累计溢出的教学接口。

## 边界用例与验证

空数组返回空数组，负数不影响递推。与带头部零的 prefix 定义不同，此题结果长度等于输入长度。
