# 元素和为目标值的子矩阵数量

类型：[[算法/04-前缀和/前缀和详解|前缀和]] · 难度：高难度 · LeetCode 1074（Hard / 困难）

题目来源：[LeetCode 1074：元素和为目标值的子矩阵数量](https://leetcode.com/problems/number-of-submatrices-that-sum-to-target/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

统计矩形整数矩阵中元素和等于 target 的非空子矩阵数量。子矩阵由连续的行和列构成。

示例：`matrix=[[1,-1],[-1,1]], target=0 → 5`。

## 从直觉到算法

直接枚举四条边并求和成本高。固定 top、bottom 两条行边界，把这些行每列的和压到 compressed 中；此时选择连续列就与一维“和为 K 的子数组”完全一致。每组行边界独立建立历史前缀频次。

## 关键步骤推演

只选第 0 行，压缩 [1,-1]，贡献 1；选两行，压缩 [0,0]，贡献 3；只选第 1 行，压缩 [-1,1]，贡献 1，总计 5。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long numSubmatrixSumTarget(int[][] matrix, long target) {
        if (matrix.length == 0 || matrix[0].length == 0) return 0;
        int rows = matrix.length, cols = matrix[0].length;
        long answer = 0;
        for (int top = 0; top < rows; top++) {
            long[] compressed = new long[cols];
            for (int bottom = top; bottom < rows; bottom++) {
                for (int col = 0; col < cols; col++) compressed[col] += matrix[bottom][col];
                Map<Long, Long> frequency = new HashMap<>();
                frequency.put(0L, 1L);
                long sum = 0;
                for (long value : compressed) {
                    sum += value;
                    answer += frequency.getOrDefault(sum - target, 0L);
                    frequency.merge(sum, 1L, Long::sum);
                }
            }
        }
        return answer;
    }
}
```

## 复杂度与输入影响

R 行 C 列时，平均时间 O(R²C)，额外空间 O(C)。可选择较短维枚举边界，使时间降为 O(min(R,C)²·max(R,C))；本文保持直观的按行实现。

## 边界用例与验证

每次更换 top 时要重置压缩数组，每次更换 bottom 时要重置前缀频次。long 用于求和与计数；不修改矩阵，要求各行等长。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
check(s.numSubmatrixSumTarget(new int[][]{{1,-1},{-1,1}},0)==5);
check(s.numSubmatrixSumTarget(new int[][]{{0,0},{0,0}},0)==9);
check(s.numSubmatrixSumTarget(new int[][]{{7}},0)==0); check(s.numSubmatrixSumTarget(new int[0][0],0)==0);
```
