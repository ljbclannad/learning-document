# 最后一块石头的重量

类型：[[算法/10-堆与优先队列/堆与优先队列详解|堆与优先队列]] · 难度：低难度 · LeetCode 1046（Easy / 简单）

题目来源：[LeetCode 1046：最后一块石头的重量](https://leetcode.com/problems/last-stone-weight/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

每次取最重的两块正整数石头相撞，相等则消失，不等则放回重量差；返回最终重量，无剩余则为零。

示例：`[3,7,2] → 2`。

## 从直觉到算法

每轮重新排序会重复工作。最大堆每次取出最重两块，剩余石头保持堆结构，只需把新差值插回。

## 关键步骤推演

取 7、3，放回 4；剩 4、2，碰撞后为 2，最终返回 2。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.Comparator;
import java.util.PriorityQueue;

class Solution {
    public int lastStoneWeight(int[] stones) {
        PriorityQueue<Integer> heap = new PriorityQueue<>(Comparator.reverseOrder());
        for (int stone : stones) heap.offer(stone);
        while (heap.size() > 1) {
            int first = heap.poll(), second = heap.poll();
            if (first != second) heap.offer(first - second);
        }
        return heap.isEmpty() ? 0 : heap.peek();
    }
}
```

## 复杂度与输入影响

逐个入堆与碰撞总时间 O(n log n)，空间 O(n)。不修改原数组。

## 边界用例与验证
