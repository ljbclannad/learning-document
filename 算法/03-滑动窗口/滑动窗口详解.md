# 滑动窗口详解

返回 [[算法/算法学习导航]]。

## 核心思想与识别信号

滑动窗口处理连续子数组或子串。它维护一个左右边界之间的统计量，并通过增删边界元素复用前一个区间的信息。连续性是前提；任意子序列问题通常不能用这种窗口直接解决。

## 执行机制与正确性依据

定长窗口每次加入一个元素并移出一个元素。变长窗口必须有可证明的收缩规则：例如无重复子串，加入新字符后只有与它相关的计数可能违约，持续移出左端直到恢复合法；覆盖子串则先扩到合法，再收缩寻找最短。先判断求最长还是最短，才能确定更新答案的位置。

## 手动推演

字符串 abca：右端加入 a、b、c 后最长长度为 3；再加入 a 时计数变成 2，移走最左 a 恢复合法，窗口变为 bca。左右边界各只前进，不会回退，因此总移动次数为线性。

## Java 入门模板

以下为本类型低难度代表题的完整实现，可作为理解状态与更新顺序的起点；它不是所有变式的通用答案。先说清状态含义，再修改模板。代码基线为 Java 17。

```java
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        if (k < 1 || k > nums.length) throw new IllegalArgumentException("窗口长度非法");
        long sum = 0;
        for (int i = 0; i < k; i++) sum += nums[i];
        long best = sum;
        for (int right = k; right < nums.length; right++) {
            sum += (long) nums[right] - nums[right - k];
            best = Math.max(best, sum);
        }
        return (double) best / k;
    }
}
```

模板复杂度：时间 O(n)，额外空间 O(1)。sum 用 long，最终转 double 除法。

## 适用边界与常见错误

含负数时，区间和并不随扩张单调增加，因此“和太大就缩左边”可能漏解，应考虑前缀和。用 char 处理的是 UTF-16 代码单元；涉及补充平面字符时需要码点序列。最小覆盖需要满足每字符次数，而非仅判断种类存在。

## 工程联系

固定样本数的移动平均可对应定长窗口。按时间的监控窗口还要处理时间戳、乱序与过期规则，不能直接等同于数组上的定长窗口。
