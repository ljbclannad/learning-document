# 最小覆盖子串

类型：[[算法/03-滑动窗口/滑动窗口详解|滑动窗口]] · 难度：高难度 · LeetCode 76（Hard / 困难）

题目来源：[LeetCode 76：最小覆盖子串](https://leetcode.com/problems/minimum-window-substring/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

找到 s 中包含 t 全部字符及其重复次数的最短连续子串；不存在则返回空串。输入按 char 处理。

示例：`s="BAAC", t="AAC" → "AAC"`。

## 从直觉到算法

need 记录还缺多少个字符，missing 记录总缺额。右端加入字符时，只有其缺额大于零才减少 missing；missing 为零即可收缩，逐个记录更短合法窗口，直到移出一个必需字符使窗口不再覆盖。

## 关键步骤推演

B 不影响缺额；两个 A 加入后仍缺 C；C 加入后合法，先记录 BAAC，再移出无关 B，记录 AAC；继续移出 A 后重新缺一个 A，停止收缩。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    public String minWindow(String s, String t) {
        if (t.isEmpty() || s.length() < t.length()) return "";
        int[] need = new int[65536];
        for (int i = 0; i < t.length(); i++) need[t.charAt(i)]++;
        int missing = t.length(), left = 0, start = 0, best = Integer.MAX_VALUE;
        for (int right = 0; right < s.length(); right++) {
            char added = s.charAt(right);
            if (need[added] > 0) missing--;
            need[added]--;
            while (missing == 0) {
                if (right - left + 1 < best) { best = right - left + 1; start = left; }
                char removed = s.charAt(left++);
                need[removed]++;
                if (need[removed] > 0) missing++;
            }
        }
        return best == Integer.MAX_VALUE ? "" : s.substring(start, start + best);
    }
}
```

## 复杂度与输入影响

时间 O(|s|+|t|)，空间 O(U)，U=65536。结果 substring 还需分配与输出长度相当的空间。

## 边界用例与验证

必须统计重复字符；t 为空要提前返回，避免合法窗口无限收缩。不能在窗口尚未覆盖时更新最短答案。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
check(s.minWindow("BAAC","AAC").equals("AAC")); check(s.minWindow("a","aa").equals(""));
check(s.minWindow("abc","").equals("")); check(s.minWindow("ADOBECODEBANC","ABC").equals("BANC"));
```
