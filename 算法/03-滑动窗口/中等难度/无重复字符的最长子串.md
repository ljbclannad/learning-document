# 无重复字符的最长子串

类型：[[算法/03-滑动窗口/滑动窗口详解|滑动窗口]] · 难度：中等难度 · LeetCode 3（Medium / 中等）

题目来源：[LeetCode 3：无重复字符的最长子串](https://leetcode.com/problems/longest-substring-without-repeating-characters/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

求字符串中不含重复字符的最长连续子串长度。本文按 Java char（UTF-16 代码单元）判断重复。

示例：`"abca" → 3`。

## 从直觉到算法

暴力枚举起点再向右扫描会重复统计。维护窗口字符次数；右端新字符出现两次时，左端不断移出字符，直到这个字符次数恢复为 1。其他字符原先不重复，因此此时整个窗口合法。

## 关键步骤推演

a、b、c 依次进入，答案变为 3；末尾 a 进入后，移出首位 a，窗口为 bca，长度仍为 3。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int[] count = new int[65536];
        int left = 0, best = 0;
        for (int right = 0; right < s.length(); right++) {
            char added = s.charAt(right);
            count[added]++;
            while (count[added] > 1) count[s.charAt(left++)]--;
            best = Math.max(best, right - left + 1);
        }
        return best;
    }
}
```

## 复杂度与输入影响

时间 O(n)，空间 O(U)，此处固定 char 字母表 U=65536；固定 U 时可视为 O(1)，并不代表只分配几个变量。

## 边界用例与验证

必须用 while 收缩；abba 在第二个 b 进入时需要移走 a 和 b。子串要求连续，不能把 acb 等跳选结果作为窗口。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
check(s.lengthOfLongestSubstring("abca")==3); check(s.lengthOfLongestSubstring("abba")==2);
check(s.lengthOfLongestSubstring("")==0); check(s.lengthOfLongestSubstring("aaaa")==1);
```
