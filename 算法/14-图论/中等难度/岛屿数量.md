# 岛屿数量

类型：[[算法/14-图论/图论详解|图论]] · 难度：中等难度 · LeetCode 200（Medium / 中等）

题目来源：[LeetCode 200：岛屿数量](https://leetcode.com/problems/number-of-islands/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

矩形字符网格中 1 为陆地、0 为水，上下左右相邻的陆地构成岛屿，求岛屿数。

示例：`[[1,1,0],[0,1,0],[1,0,1]] → 3`。

## 从直觉到算法

扫描所有格子，遇到未访问陆地就发现一个新连通块，计数加一并 BFS 标记整个岛屿。被标记的陆地不会再次触发计数。

## 关键步骤推演

左上陆地连通三个格子，第一次 BFS 一并标记；最下行左侧和右侧互不相连，各贡献一个岛屿，总计 3。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int numIslands(char[][] grid) {
        if (grid.length == 0 || grid[0].length == 0) return 0;
        int rows = grid.length, cols = grid[0].length, count = 0;
        boolean[][] seen = new boolean[rows][cols];
        int[] dr = {-1,1,0,0}, dc = {0,0,-1,1};
        Deque<int[]> queue = new ArrayDeque<>();
        for (int r = 0; r < rows; r++) for (int c = 0; c < cols; c++) {
            if (grid[r][c] != '1' || seen[r][c]) continue;
            count++; seen[r][c] = true; queue.addLast(new int[]{r,c});
            while (!queue.isEmpty()) {
                int[] cell = queue.removeFirst();
                for (int d = 0; d < 4; d++) {
                    int nr = cell[0] + dr[d], nc = cell[1] + dc[d];
                    if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && grid[nr][nc] == '1' && !seen[nr][nc]) {
                        seen[nr][nc] = true; queue.addLast(new int[]{nr,nc});
                    }
                }
            }
        }
        return count;
    }
}
```

## 复杂度与输入影响

时间 O(RC)，visited 和队列最坏 O(RC)，不修改输入。

## 边界用例与验证

只允许四向连接，对角相邻不合并。扫描发现新岛时立即标记并入队，后续邻居也同样处理。空网格返回零。
