# 矩阵中的最长递增路径

类型：[[算法/14-图论/图论详解|图论]] · 难度：高难度 · LeetCode 329（Hard / 困难）

题目来源：[LeetCode 329：矩阵中的最长递增路径](https://leetcode.com/problems/longest-increasing-path-in-a-matrix/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

在整数矩阵中上下左右移动，寻找数值严格递增的最长路径长度；不能斜走或越界。

示例：`[[1,2],[4,3]] → 4，对应 1→2→3→4`。

## 从直觉到算法

将较小格到较大邻格视为有向边，严格递增保证无环。统计每格来自更小邻格的入度，先入队所有入度为零的格子，按层做拓扑删除。顶点只有在所有前驱处理后才可进入下一层，因此层数等于最长路径长度，而不是普通 BFS 的最短距离。

## 关键步骤推演

1 入度为零，第一层移除后释放 2；第二层释放 3；第三层释放 4，最终四层。注意 1 也直接连到 4，但 4 必须等另一个前驱 3 处理完。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int longestIncreasingPath(int[][] matrix) {
        if (matrix.length == 0 || matrix[0].length == 0) return 0;
        int rows = matrix.length, cols = matrix[0].length;
        int[][] degree = new int[rows][cols];
        int[] dr = {-1,1,0,0}, dc = {0,0,-1,1};
        Deque<int[]> queue = new ArrayDeque<>();
        for (int r = 0; r < rows; r++) for (int c = 0; c < cols; c++) {
            for (int d = 0; d < 4; d++) {
                int nr = r + dr[d], nc = c + dc[d];
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && matrix[nr][nc] < matrix[r][c]) degree[r][c]++;
            }
            if (degree[r][c] == 0) queue.addLast(new int[]{r,c});
        }
        int length = 0;
        while (!queue.isEmpty()) {
            int size = queue.size(); length++;
            for (int i = 0; i < size; i++) {
                int[] cell = queue.removeFirst();
                for (int d = 0; d < 4; d++) {
                    int nr = cell[0] + dr[d], nc = cell[1] + dc[d];
                    if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && matrix[nr][nc] > matrix[cell[0]][cell[1]]) {
                        if (--degree[nr][nc] == 0) queue.addLast(new int[]{nr,nc});
                    }
                }
            }
        }
        return length;
    }
}
```

## 复杂度与输入影响

时间 O(RC)，每格只检查常数个邻居；入度和队列空间 O(RC)。迭代实现不依赖深递归栈。

## 边界用例与验证

相等数值之间不建边，全相等矩阵答案为 1。必须按当前层固定 size 处理，否则一次 while 可能把全部层混在一起。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java

```
