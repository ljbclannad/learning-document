# 寻找图中是否存在路径

类型：[[算法/14-图论/图论详解|图论]] · 难度：低难度 · LeetCode 1971（Easy / 简单）

题目来源：[LeetCode 1971：寻找图中是否存在路径](https://leetcode.com/problems/find-if-path-exists-in-graph/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

给定 n 个顶点和无向边，判断 source 到 destination 是否连通。顶点编号为 0～n-1。

示例：`n=4，edges=[[0,1],[1,2]]，source=0，destination=2 → true`。

## 从直觉到算法

构造双向邻接表，从 source 开始 BFS，所有入队顶点都是可达的。如果发现目标则返回 true；队列耗尽仍未找到，则目标不在同一连通块。

## 关键步骤推演

队列先有 0，取出后入队 1；取出 1 后入队 2；取出 2 命中目标，孤立点 3 不影响结果。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public boolean validPath(int n, int[][] edges, int source, int destination) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] edge : edges) { graph.get(edge[0]).add(edge[1]); graph.get(edge[1]).add(edge[0]); }
        boolean[] seen = new boolean[n];
        Deque<Integer> queue = new ArrayDeque<>(); queue.addLast(source); seen[source] = true;
        while (!queue.isEmpty()) {
            int node = queue.removeFirst();
            if (node == destination) return true;
            for (int next : graph.get(node)) {
                if (!seen[next]) { seen[next] = true; queue.addLast(next); }
            }
        }
        return false;
    }
}
```

## 复杂度与输入影响

时间 O(V+E)，邻接表 O(V+E)，队列与 visited O(V)。要求顶点编号合法。

## 边界用例与验证

source==destination 即使没有边也可达。标记入队而不是出队，避免菱形路径把同一顶点反复加入。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
check(s.validPath(4,new int[][]{{0,1},{1,2}},0,2));check(!s.validPath(4,new int[][]{{0,1},{1,2}},0,3));
check(s.validPath(1,new int[0][0],0,0));check(s.validPath(3,new int[][]{{0,1},{1,2},{2,0}},2,0));
```

## 面试追问与变式

大量连通性查询时并查集更适合预处理；若要求最短路径，应增加 parent 数组并反向恢复。
