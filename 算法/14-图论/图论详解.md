# 图论详解

返回 [[算法/算法学习导航]]。

## 核心思想与识别信号

图由顶点与边组成，可以表示关系、依赖或状态转移。先确认有向或无向、是否带权、是否可能成环，再选遍历、最短路、拓扑排序或连通性算法。网格可视为隐式图，每个格子是顶点，相邻关系是边。

## 执行机制与正确性依据

BFS 用队列逐层探索，顶点第一次入队就标记已见，避免多条边导致重复入队。DFS 也能找连通块，但深图递归有栈风险。DAG 的拓扑排序不断移除入度为零的顶点；若按层移除，每个顶点所在层等于其最长前驱路径长度加一。

## 手动推演

边 0—1、1—2，起点 0：标记并入队 0，取出后发现 1，再发现 2。网格严格递增路径把较小格指向较大邻格；沿边数值严格增加，不可能回到原点，因此得到 DAG，可以使用拓扑分层。

## Java 入门模板

以下为本类型低难度代表题的完整实现，可作为理解状态与更新顺序的起点；它不是所有变式的通用答案。先说清状态含义，再修改模板。代码基线为 Java 17。

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public boolean validPath(int n, int[][] edges, int source, int destination) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] edge : edges) { graph.get(edge[0]).add(edge[1]); graph.get(edge[1]).add(edge[0]); }
        boolean[] seen = new boolean[n];
        Deque<Integer> queue = new ArrayDeque<>(); queue.addLast(source); seen[source] = true;
        while (!queue.isEmpty()) {
            int node = queue.removeFirst();
            if (node == destination) return true;
            for (int next : graph.get(node)) {
                if (!seen[next]) { seen[next] = true; queue.addLast(next); }
            }
        }
        return false;
    }
}
```

模板复杂度：时间 O(V+E)，邻接表 O(V+E)，队列与 visited O(V)。要求顶点编号合法。

## 适用边界与常见错误

无向图邻接表要添加双向边。visited 应在入队时设置。BFS 的最短距离结论只直接适用于无权或等权边；带权最短路需另选算法。允许相等值移动会破坏递增图无环的证明。

## 工程联系

模块依赖和任务先后关系可建模为图；实际任务重试、失败传播、资源约束还要单独定义。首批覆盖连通性、网格遍历和 DAG，后续可扩展并查集、Dijkstra、最小生成树。
