# 不同的子序列

类型：[[算法/13-动态规划/动态规划详解|动态规划]] · 难度：高难度 · LeetCode 115（Hard / 困难）

题目来源：[LeetCode 115：不同的子序列](https://leetcode.com/problems/distinct-subsequences/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

从 s 删除任意字符且不改变剩余字符顺序，统计有多少种下标选择能得到 t。不同下标选择即使形成相同文本也分别计数。

示例：`s="aaa", t="aa" → 3`。

## 从直觉到算法

令 dp[i][j] 为 s 前 i 个字符组成 t 前 j 个字符的数量。不使用 s 当前字符得到 dp[i-1][j]；字符相等时还可使用它，增加 dp[i-1][j-1]。压成一维后必须从右往左更新，确保 dp[j-1] 仍属于上一轮。

## 关键步骤推演

初始 dp=[1,0,0]；三个 a 依次处理后变为 [1,1,0]、[1,2,1]、[1,3,3]，答案 3。若正序更新，第一个 a 就可能被重复使用两次。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.math.BigInteger;
import java.util.Arrays;

class Solution {
    public BigInteger numDistinct(String s, String t) {
        BigInteger[] dp = new BigInteger[t.length() + 1];
        Arrays.fill(dp, BigInteger.ZERO); dp[0] = BigInteger.ONE;
        for (int i = 0; i < s.length(); i++) {
            for (int j = t.length(); j >= 1; j--) {
                if (s.charAt(i) == t.charAt(j - 1)) dp[j] = dp[j].add(dp[j - 1]);
            }
        }
        return dp[t.length()];
    }
}
```

## 复杂度与输入影响

有 O(|s|·|t|) 次状态更新，O(|t|) 个状态。使用 BigInteger 保证中间计数准确；若最大整数位数为 B，加法时间 O(B)，总位运算复杂度 O(|s|·|t|·B)，状态存储 O(|t|·B)。

## 边界用例与验证

平台保证最终答案适合 int，但某些前缀状态仍可很大。本文返回 BigInteger，提交平台时可在其结果契约下调用 intValueExact()。空目标定义为一种空选择。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。
