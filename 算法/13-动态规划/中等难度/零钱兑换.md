# 零钱兑换

类型：[[算法/13-动态规划/动态规划详解|动态规划]] · 难度：中等难度 · LeetCode 322（Medium / 中等）

题目来源：[LeetCode 322：零钱兑换](https://leetcode.com/problems/coin-change/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

硬币面额均为正整数，每种可无限使用，求凑出非负 amount 的最少硬币数，无解返回 -1。

示例：`coins=[1,3,4], amount=6 → 2`。

## 从直觉到算法

令 dp[x] 表示金额 x 的最少枚数。枚举最后使用的硬币 c，若 x-c 可达，就用 dp[x-c]+1 更新。按金额从小到大计算，使所有依赖先完成。

## 关键步骤推演

dp[0]=0；dp[1]=1、dp[2]=2、dp[3]=1、dp[4]=1、dp[5]=2；dp[6] 选择 dp[3]+1=2。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.Arrays;

class Solution {
    public int coinChange(int[] coins, int amount) {
        if (amount < 0 || amount > 10000) throw new IllegalArgumentException("amount 应在 0 到 10000 之间");
        for (int coin : coins) if (coin <= 0) throw new IllegalArgumentException("面额必须为正数");
        int[] dp = new int[amount + 1]; Arrays.fill(dp, amount + 1); dp[0] = 0;
        for (int value = 1; value <= amount; value++) {
            for (int coin : coins) {
                if (coin <= value) dp[value] = Math.min(dp[value], dp[value - coin] + 1);
            }
        }
        return dp[amount] > amount ? -1 : dp[amount];
    }
}
```

## 复杂度与输入影响

设硬币种类 C、金额 A，时间 O(A·C)，空间 O(A)。适用于 A 能在内存中分配数组的范围，本文教学及平台输入取 A≤10000。

面额零或负数破坏依赖顺序，必须拒绝。amount=0 返回 0。不可达值用 amount+1，因正面额下任何可达解最多用 amount 枚。
