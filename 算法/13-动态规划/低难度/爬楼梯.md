# 爬楼梯

类型：[[算法/13-动态规划/动态规划详解|动态规划]] · 难度：低难度 · LeetCode 70（Easy / 简单）

题目来源：[LeetCode 70：爬楼梯](https://leetcode.com/problems/climbing-stairs/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

每次可爬 1 或 2 级，求到达 n 级的方法数。本文支持 0≤n≤45，n=0 定义为一种空走法。

示例：`n=4 → 5`。

## 从直觉到算法

最后一步只能从 n-1 或 n-2 来，两类走法互不重叠且覆盖全部，因此 f(n)=f(n-1)+f(n-2)。只需保留前两个状态，避免递归重复计算。

## 关键步骤推演

f(0)=1、f(1)=1，依次得到 f(2)=2、f(3)=3、f(4)=5。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    public int climbStairs(int n) {
        if (n < 0 || n > 45) throw new IllegalArgumentException("n 应在 0 到 45 之间");
        int previous = 1, current = 1;
        for (int i = 2; i <= n; i++) {
            int next = previous + current;
            previous = current; current = next;
        }
        return current;
    }
}
```

## 复杂度与输入影响

时间 O(n)，额外空间 O(1)。本实现限制 n≤45，int 结果安全。

## 边界用例与验证

不能无范围限制地宣称 int 足够；n=46 已超出 int。若要扩展范围，应使用 long 或 BigInteger 并重新说明边界。
