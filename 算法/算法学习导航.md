# 算法学习导航

本专题面向 Java 后端面试，首批包含 **14 类算法、42 道代表题**。每类均有类型详解，以及“低难度 / 中等难度 / 高难度”三个题目目录，每个难度先收录一道题。

## 目录约定

```text
算法/
├── 算法学习导航.md
├── 01-数组与双指针/

│   └── 高难度/接雨水.md
└── ……其余类型采用同一结构
```

旧的算法笔记与 PDF 保留原位。本专题是新增的结构化学习入口，不迁移、不删除旧内容。后续新增题目按主要解法归类，每题维护一份正文，跨类型用 Obsidian 链接关联。

低难度对应平台 Easy，中等难度对应 Medium，高难度对应 Hard。难度不等于学习先后或代码长度，例如分发糖果虽然是困难题，双向扫描实现并不长。题目链接指向 LeetCode 官方页面；题意采用概述，详解与 Java 实现独立编写。

## 学习顺序与掌握标准

第一轮先做数组、哈希表、滑动窗口、前缀和、链表、栈与二分的低难度和中等题，练习状态定义、循环不变量和边界处理。第二轮进入排序、树、堆、回溯、贪心、动态规划、图论的基础题。第三轮再做困难题，重点讲清多种机制如何组合。

每篇详解提供核心思想、执行机制、手动推演、Java 入门模板、边界和工程联系。每道题提供题意、样例、推导、完整实现、复杂度、可执行断言以及追问。不要把读过题解当成掌握：至少能脱稿说明为什么不会漏解，独立写出代码，并给出一个会让错误实现失败的输入。

## Java 示例与验证约定

代码基线为 Java 17。题目中的首个 Java 代码块为可独立编译的 `Solution` 类，第二个代码块为测试方法体。每道题应在独立目录编译，避免同名 `Solution` 冲突。把断言片段放入类内的 `main` 方法，并添加下面的校验函数即可运行：

```java
private static void check(boolean condition) {
    if (!condition) throw new AssertionError("用例失败");
}
public static void main(String[] args) {
    Solution s = new Solution();
    // 在此插入该题的断言片段。
}
```

测试片段若使用集合辅助类，按需显式导入 `java.util.Arrays`、`java.util.Collections`、`java.util.HashSet`、`java.util.List`；若使用大整数，导入 `java.math.BigInteger`。运行 `javac -encoding UTF-8 Solution.java`，再运行 `java Solution`。`check` 不依赖 JVM 的 `-ea` 开关。

部分教学接口返回 `long`、`long[]` 或 `BigInteger`，用来显式处理累计值、面积及计数溢出；与平台签名不同时已在题目正文说明。不要直接批量改成 int，应先核实平台约束。示例不是通用生产库，输入范围、可变性和字符语义以各题正文为准。

- 环境：本机 JDK 17.0.11，使用 `javac` 编译、`java` 执行，无外部库依赖。
