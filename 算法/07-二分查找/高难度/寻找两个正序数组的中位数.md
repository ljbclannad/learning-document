# 寻找两个正序数组的中位数

类型：[[算法/07-二分查找/二分查找详解|二分查找]] · 难度：高难度 · LeetCode 4（Hard / 困难）

题目来源：[LeetCode 4：寻找两个正序数组的中位数](https://leetcode.com/problems/median-of-two-sorted-arrays/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

两个升序数组总长度至少为 1，求合并后的中位数，目标时间 O(log(m+n))。

示例：`a=[1,4], b=[2,3] → 2.5`。

## 从直觉到算法

不实际合并，而是在较短数组上二分切分位置 i，并由左半总长度确定另一数组切分 j。正确切分需满足 aLeft<=bRight 且 bLeft<=aRight，此时整个左半都不大于右半。奇数取左半最大，偶数取左右边界平均。

## 关键步骤推演

总长 4，左半应放 2 项；i=1、j=1 时左边界为 1、2，右边界为 4、3，满足交叉条件，取 (max(1,2)+min(4,3))/2=2.5。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    public double findMedianSortedArrays(int[] a, int[] b) {
        if (a.length > b.length) return findMedianSortedArrays(b, a);
        int m = a.length, n = b.length;
        if (m + n == 0) throw new IllegalArgumentException("两个数组不能同时为空");
        int left = 0, right = m;
        while (left <= right) {
            int i = left + (right - left) / 2, j = (m + n + 1) / 2 - i;
            long aLeft = i == 0 ? Long.MIN_VALUE : a[i - 1];
            long aRight = i == m ? Long.MAX_VALUE : a[i];
            long bLeft = j == 0 ? Long.MIN_VALUE : b[j - 1];
            long bRight = j == n ? Long.MAX_VALUE : b[j];
            if (aLeft <= bRight && bLeft <= aRight) {
                if ((m + n) % 2 == 1) return Math.max(aLeft, bLeft);
                return (Math.max(aLeft, bLeft) + Math.min(aRight, bRight)) / 2.0;
            }
            if (aLeft > bRight) right = i - 1;
            else left = i + 1;
        }
        throw new IllegalArgumentException("输入必须有序");
    }
}
```

## 复杂度与输入影响

时间 O(log(min(m,n)+1))，空间 O(1)，交换数组参数最多一次。

## 边界用例与验证

切分位可在 0 或长度处，用正负 long 极值代表缺失边界；真实值相加前转 long。两个数组都为空属于非法输入。
