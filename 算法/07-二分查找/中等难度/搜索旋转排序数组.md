# 搜索旋转排序数组

类型：[[算法/07-二分查找/二分查找详解|二分查找]] · 难度：中等难度 · LeetCode 33（Medium / 中等）

题目来源：[LeetCode 33：搜索旋转排序数组](https://leetcode.com/problems/search-in-rotated-sorted-array/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

互不相同的升序数组经过一次旋转，查找 target 的下标，不存在返回 -1。

示例：`nums=[4,5,6,7,0,1,2], target=0 → 4`。

## 从直觉到算法

旋转点最多一个，所以中点左右至少一半有序。若左半有序，检查 target 是否处于 [nums[left],nums[mid])；在则搜索左半，否则右半。右半有序时对称处理。

## 关键步骤推演

中点值 7，左半 [4,5,6,7] 有序但不含 0，排除；余下 [0,1,2]，中点 1，目标在左半，最终定位 0。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) return mid;
            if (nums[left] <= nums[mid]) {
                if (nums[left] <= target && target < nums[mid]) right = mid - 1;
                else left = mid + 1;
            } else {
                if (nums[mid] < target && target <= nums[right]) left = mid + 1;
                else right = mid - 1;
            }
        }
        return -1;
    }
}
```

## 复杂度与输入影响

时间 O(log n)，空间 O(1)，依赖无重复值。

## 边界用例与验证

nums[left]<=nums[mid] 包含 left==mid 的单元素左半。边界目标要用一端闭一端开，mid 已提前检查。
