# 二分查找

类型：[[算法/07-二分查找/二分查找详解|二分查找]] · 难度：低难度 · LeetCode 704（Easy / 简单）

题目来源：[LeetCode 704：二分查找](https://leetcode.com/problems/binary-search/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

在升序且元素互不相同的整数数组中查找 target，下标不存在返回 -1。

示例：`nums=[1,3,5,7,9], target=7 → 3`。

## 从直觉到算法

数组有序，mid 小于目标时，mid 及左侧都不可能是答案；反之排除右侧。用闭区间维护所有尚未排除的位置。

## 关键步骤推演

left=0、right=4，mid=2 的值是 5；left 改为 3，mid=3 命中 7。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) return mid;
            if (nums[mid] < target) left = mid + 1;
            else right = mid - 1;
        }
        return -1;
    }
}
```

## 复杂度与输入影响

时间 O(log n)，空间 O(1)。

## 边界用例与验证

闭区间用 left<=right；空数组 right=-1，不进入循环。不要混用半开区间模板的 right=mid。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java
check(s.search(new int[]{1,3,5,7,9},7)==3);check(s.search(new int[]{1},0)==-1);
check(s.search(new int[]{1},1)==0);check(s.search(new int[0],1)==-1);
```
