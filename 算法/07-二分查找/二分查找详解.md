# 二分查找详解

返回 [[算法/算法学习导航]]。

## 核心思想与识别信号

二分每次排除一半候选，关键是可判定的单调关系，而不只是“数组排好序”。可以查值，也可以找第一个满足条件的位置，或在答案范围上二分。开始前先写明候选区间的开闭和失败返回值。

## 执行机制与正确性依据

最基础的闭区间 [left,right] 查找：小于目标时令 left=mid+1，大于目标时令 right=mid-1；每轮严格缩小区间。下界查找常用半开区间 [left,right)，保留第一个不小于目标的位置。旋转数组则先识别哪一半有序，再判断目标是否落在该半区。

## 手动推演

[1,3,5,7,9] 查 7：中点 5 小于目标，排除左半含中点；余下 [7,9]，中点为 7，命中。每次排除必须包含已经确认不可能的位置，否则可能卡在同一 mid。

## Java 入门模板

以下为本类型低难度代表题的完整实现，可作为理解状态与更新顺序的起点；它不是所有变式的通用答案。先说清状态含义，再修改模板。代码基线为 Java 17。

```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) return mid;
            if (nums[mid] < target) left = mid + 1;
            else right = mid - 1;
        }
        return -1;
    }
}
```

模板复杂度：时间 O(log n)，空间 O(1)。

## 适用边界与常见错误

中点用 left+(right-left)/2 避免加法溢出。重复值会削弱旋转数组的方向判断，最坏退化为 O(n)。浮点二分要用精度或迭代次数终止；不能直接照搬整数的 ±1。答案二分需要证明可行性谓词单调。

## 工程联系

阈值配置、已排序时间戳定位适合二分；分库分表或分页不因用了二分就保证对数访问成本，仍要看远端查询和数据索引。
