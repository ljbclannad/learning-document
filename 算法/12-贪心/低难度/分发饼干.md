# 分发饼干

类型：[[算法/12-贪心/贪心详解|贪心]] · 难度：低难度 · LeetCode 455（Easy / 简单）

题目来源：[LeetCode 455：分发饼干](https://leetcode.com/problems/assign-cookies/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

每个孩子有胃口 g，每块饼干有大小 s，每人最多一块且饼干大小至少为胃口，求最多能满足的孩子数。

示例：`g=[1,2,3], s=[1,2] → 2`。

## 从直觉到算法

两数组排序，从胃口最小的孩子开始，尝试最小未用饼干；太小则跳过，足够就匹配。给最容易满足的孩子使用最小足够饼干，不会浪费能满足更大胃口的资源。

## 关键步骤推演

饼干 1 满足胃口 1，饼干 2 满足胃口 2，无剩余饼干，答案 2。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.Arrays;

class Solution {
    public int findContentChildren(int[] greed, int[] cookies) {
        Arrays.sort(greed); Arrays.sort(cookies);
        int child = 0;
        for (int cookie : cookies) {
            if (child < greed.length && cookie >= greed[child]) child++;
        }
        return child;
    }
}
```

## 复杂度与输入影响

时间 O(g log g+s log s)，扫描 O(g+s)；除排序辅助开销外 O(1) 空间。修改两个输入数组的顺序。

## 边界用例与验证

小饼干不能满足当前最小胃口，就也不能满足后面更大胃口，可以安全跳过。任一数组为空时答案为零。
