# 分发糖果

类型：[[算法/12-贪心/贪心详解|贪心]] · 难度：高难度 · LeetCode 135（Hard / 困难）

题目来源：[LeetCode 135：分发糖果](https://leetcode.com/problems/candy/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

每个孩子至少一颗糖，评分高于相邻孩子时糖果也必须更多，求最少糖果总量；相同评分无大小约束。

示例：`ratings=[1,0,2] → 5，对应糖果 [2,1,2]`。

## 从直觉到算法

从左向右计算满足左邻约束的最小糖数，再从右向左补足右邻约束，更新时取 max 保留已有左约束。任何合法分配都必须不小于这两个方向的下界，逐点取最大同时满足两边，因此总量最小。

## 关键步骤推演

初始 [1,1,1]；左扫得到 [1,1,2]；右扫时第 0 个评分高于第 1 个，补为 2，最终 [2,1,2]。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
import java.util.Arrays;

class Solution {
    public long candy(int[] ratings) {
        int n = ratings.length;
        int[] candies = new int[n]; Arrays.fill(candies, 1);
        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1]) candies[i] = candies[i - 1] + 1;
        }
        for (int i = n - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1]) candies[i] = Math.max(candies[i], candies[i + 1] + 1);
        }
        long total = 0;
        for (int value : candies) total += value;
        return total;
    }
}
```

## 复杂度与输入影响

时间 O(n)，空间 O(n)，总量用 long；不修改评分数组。

## 边界用例与验证

右扫时不能直接覆盖为右邻+1，否则可能破坏左邻约束。平台是困难题，但双向扫描解法比常数空间山峰法更适合第一轮学习。
