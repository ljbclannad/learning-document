# 跳跃游戏

类型：[[算法/12-贪心/贪心详解|贪心]] · 难度：中等难度 · LeetCode 55（Medium / 中等）

题目来源：[LeetCode 55：跳跃游戏](https://leetcode.com/problems/jump-game/)。以下题意为中文概述，示例和解法用于学习；完整平台约束以原题为准。

## 题意与输入输出

非负整数 nums[i] 表示从位置 i 最多可前进的步数，判断能否从 0 到达最后位置。数组非空。

示例：`[2,3,1,1,4] → true；[3,2,1,0,4] → false`。

## 从直觉到算法

只维护所有已检查且可达位置能覆盖的最远下标 farthest。若当前 i 超出它，说明所有已知可达位置都无法跨过这个缺口，后面也不可能到达；否则用 i+nums[i] 扩展边界。

## 关键步骤推演

第一个示例从 0 能到 2，扫描到 1 又把边界扩到 4，覆盖终点。第二例最多到 3，而位置 3 的跳跃长度为零，无法到达 4。

## Java 实现

以下是可独立编译的完整 `Solution` 类，基线 Java 17；没有 `main` 入口。链表、树的辅助节点定义包含在类中，提交平台时应替换为平台提供的节点类型。除正文另有约定外，引用参数非 null，输入满足题目结构约束；实现未做全部非法输入校验。

```java
class Solution {
    public boolean canJump(int[] nums) {
        if (nums.length == 0) return false;
        long farthest = 0;
        for (int i = 0; i < nums.length; i++) {
            if (i > farthest) return false;
            farthest = Math.max(farthest, (long) i + nums[i]);
            if (farthest >= nums.length - 1) return true;
        }
        return false;
    }
}
```

## 复杂度与输入影响

时间 O(n)，空间 O(1)。使用 long 计算可达位置，避免 i+nums[i] 溢出。

## 边界用例与验证

不能强制每次跳最远：到达更远位置不代表后续跳得更远。单个元素即已到终点，值为零也返回 true。

以下断言片段应放在同一个 `Solution` 类的静态测试入口中，`s` 是 `new Solution()`，`check` 在条件为假时抛出 `AssertionError`。测试用的 `Arrays`、`Collections`、`HashSet`、`List` 等类型需要显式导入；统一运行方式见导航中的验证说明。

```java

```
