### 2. 预约模块深挖

#### 2.1 如何防止重复预约？

**面试官：用户点击预约按钮，如何防止重复提交？**

**答：**

**问题分析：**
- 用户可能多次点击预约按钮
- 网络抖动导致重复请求
- 需要保证同一用户同一时段只能预约一次

**解决方案：分布式锁 + 数据库唯一索引**

**1. 前端防抖**
```javascript
// 防止用户快速点击
let isSubmitting = false;

function submitAppointment() {
    if (isSubmitting) {
        return;
    }
    
    isSubmitting = true;
    
    axios.post('/appointment/create', data)
        .finally(() => {
            isSubmitting = false;
        });
}
```

**2. 后端分布式锁**
```java
@Service
public class AppointmentService {
    
    @Autowired
    private RedissonClient redisson;
    
    @Transactional
    public void createAppointment(AppointmentDTO dto) {
        Long userId = dto.getUserId();
        Long doctorId = dto.getDoctorId();
        String time = dto.getAppointmentTime();
        
        // 分布式锁：用户+医生+时间
        String lockKey = String.format("lock:appointment:%d:%d:%s", 
            userId, doctorId, time);
        
        RLock lock = redisson.getLock(lockKey);
        
        try {
            // 尝试加锁，最多等待3秒
            if (lock.tryLock(3, 10, TimeUnit.SECONDS)) {
                // 1. 检查是否已预约
                if (appointmentMapper.exists(userId, doctorId, time)) {
                    throw new BusinessException("已预约，请勿重复提交");
                }
                
                // 2. 检查医生排班是否可预约
                Schedule schedule = scheduleMapper.selectByDoctorAndTime(doctorId, time);
                if (schedule.getRemainCount() <= 0) {
                    throw new BusinessException("该时段已满");
                }
                
                // 3. 创建预约
                Appointment appointment = new Appointment();
                appointment.setUserId(userId);
                appointment.setDoctorId(doctorId);
                appointment.setAppointmentTime(time);
                appointmentMapper.insert(appointment);
                
                // 4. 扣减排班名额
                scheduleMapper.decrementRemainCount(doctorId, time);
                
                // 5. 发送MQ通知
                rabbitTemplate.convertAndSend("appointment.create", appointment);
            } else {
                throw new BusinessException("系统繁忙，请稍后重试");
            }
        } finally {
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }
}
```

**3. 数据库唯一索引**
```sql
-- 预约表添加唯一索引
CREATE UNIQUE INDEX uk_user_doctor_time 
ON t_appointment(user_id, doctor_id, appointment_time);
```

**优化效果：**
- 重复预约从100单/天降到0
- 预约成功率从90%提升到99%

#### 2.2 如何实现预约超时自动取消？

**面试官：用户预约后30分钟未就诊，如何自动取消？**

**答：**

**方案：RabbitMQ延迟队列**

**1. 配置延迟队列**
```java
@Configuration
public class DelayQueueConfig {
    
    // 延迟队列（不消费，等待过期）
    @Bean
    public Queue delayQueue() {
        Map<String, Object> args = new HashMap<>();
        args.put("x-dead-letter-exchange", "appointment.dlx.exchange");
        args.put("x-dead-letter-routing-key", "appointment.cancel");
        args.put("x-message-ttl", 1800000);  // 30分钟
        
        return new Queue("appointment.delay.queue", true, false, false, args);
    }
    
    // 死信交换机
    @Bean
    public DirectExchange dlxExchange() {
        return new DirectExchange("appointment.dlx.exchange");
    }
    
    // 死信队列（真正消费）
    @Bean
    public Queue dlxQueue() {
        return new Queue("appointment.cancel.queue");
    }
    
    @Bean
    public Binding dlxBinding() {
        return BindingBuilder.bind(dlxQueue())
            .to(dlxExchange())
            .with("appointment.cancel");
    }
}
```

**2. 发送延迟消息**
```java
@Service
public class AppointmentService {
    
    @Autowired
    private RabbitTemplate rabbitTemplate;
    
    @Transactional
    public void createAppointment(AppointmentDTO dto) {
        // 创建预约
        Appointment appointment = appointmentMapper.insert(dto);
        
        // 发送延迟消息
        rabbitTemplate.convertAndSend("appointment.delay.queue", appointment);
    }
}
```

**3. 消费延迟消息**
```java
@Service
public class AppointmentCancelConsumer {
    
    @RabbitListener(queues = "appointment.cancel.queue")
    public void handleCancel(Appointment appointment) {
        // 检查预约状态
        Appointment dbAppointment = appointmentMapper.selectById(appointment.getId());
        
        if (dbAppointment.getStatus() == AppointmentStatus.PENDING) {
            // 取消预约
            appointmentMapper.updateStatus(appointment.getId(), AppointmentStatus.CANCELLED);
            
            // 恢复排班名额
            scheduleMapper.incrementRemainCount(
                appointment.getDoctorId(), 
                appointment.getAppointmentTime()
            );
            
            // 发送通知
            notifyService.sendCancelNotice(appointment.getUserId());
        }
    }
}
```

**优化效果：**
- 自动取消率：5%
- 排班名额利用率从80%提升到95%

### 3. 处方模块深挖

#### 3.1 如何保证处方流程的数据一致性？

**面试官：处方流程包括开具处方、审核处方、发药，如何保证数据一致性？**

**答：**

**问题分析：**
- 处方流程涉及多个服务（处方服务、审核服务、药房服务）
- 需要保证要么全部成功，要么全部失败

**解决方案：Seata AT模式**

**1. 配置Seata**
```yaml
seata:
  enabled: true
  application-id: prescription-service
  tx-service-group: prescription-group
  service:
    vgroup-mapping:
      prescription-group: default
  registry:
    type: nacos
    nacos:
      server-addr: localhost:8848
```

**2. 开启全局事务**
```java
@Service
public class PrescriptionService {
    
    @Autowired
    private PrescriptionMapper prescriptionMapper;
    
    @Autowired
    private AuditServiceClient auditServiceClient;
    
    @Autowired
    private PharmacyServiceClient pharmacyServiceClient;
    
    @GlobalTransactional(name = "create-prescription", rollbackFor = Exception.class)
    public void createPrescription(PrescriptionDTO dto) {
        // 1. 开具处方（本地事务）
        Prescription prescription = new Prescription();
        prescription.setDoctorId(dto.getDoctorId());
        prescription.setPatientId(dto.getPatientId());
        prescription.setMedicines(dto.getMedicines());
        prescriptionMapper.insert(prescription);
        
        // 2. 提交审核（远程调用）
        auditServiceClient.submitAudit(prescription.getId());
        
        // 3. 通知药房（远程调用）
        pharmacyServiceClient.notifyPharmacy(prescription.getId());
        
        // 任何一步失败，Seata自动回滚所有操作
    }
}
```

**3. 分支事务**

### 5. 秒杀模块深挖

#### 5.1 如何设计秒杀系统？

**面试官：10万人抢100件商品，如何设计？**

**答：**

**核心思路：限流 + 削峰 + 异步**

**架构设计：**
```
用户请求
   ↓
Nginx（限流10万QPS）
   ↓
Gateway（限流5万QPS）
   ↓
秒杀服务（限流1万QPS）
   ↓
Redis预扣库存
   ↓
RabbitMQ（削峰）
   ↓
订单服务（异步创建订单）
```

**详细实现：**

**1. 前端限流**
```javascript

function seckill() {
```

**3. Gateway限流**
```yaml

    gateway:
      routes:
        - id: seckill-service
          uri: lb://seckill-service
          predicates:
            - Path=/seckill/**
          filters:
            - name: RequestRateLimiter
              args:
                redis-rate-limiter.replenishRate: 5000  # 每秒生成5000个令牌
                redis-rate-limiter.burstCapacity: 10000  # 令牌桶容量
```

**4. Redis预扣库存**
```java
@Service
public class SeckillService {
    
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    @Autowired
    private RabbitTemplate rabbitTemplate;
    
    public SeckillResult seckill(Long userId, Long productId) {
        String stockKey = "seckill:stock:" + productId;
        
        // Lua脚本保证原子性
        String script = 
            "local stock = redis.call('get', KEYS[1]) " +
            "if stock and tonumber(stock) > 0 then " +
            "    redis.call('decr', KEYS[1]) " +
            "    return 1 " +
            "else " +
            "    return 0 " +
            "end";
        
        Long result = redisTemplate.execute(
            new DefaultRedisScript<>(script, Long.class),
            Collections.singletonList(stockKey)
        );
        
        if (result == 1) {
            // 发送MQ，异步创建订单
            SeckillMessage message = new SeckillMessage(userId, productId);
            rabbitTemplate.convertAndSend("seckill.order", message);
            
            return SeckillResult.success("抢购成功");
        } else {
            return SeckillResult.fail("商品已售罄");
        }
    }
}
```

**5. MQ削峰**
```java
@Service
```

- 中文文档完善，社区活跃

**3. 性能更好**
- Nacos：支持百万级服务注册
- Sentinel：性能损耗小于5%

**对比：**

| 功能 | Spring Cloud Netflix | Spring Cloud Alibaba |
|------|---------------------|---------------------|
| 服务注册 | Eureka | Nacos |
| 配置中心 | Config | Nacos Config |
| 服务保护 | Hystrix | Sentinel |
| 网关 | Zuul | Gateway |
| 负载均衡 | Ribbon | LoadBalancer |

**项目实例：** 医疗平台使用Nacos，一个组件解决服务注册和配置管理

### 7. 为什么选择Seata？

**面试官：为什么选择Seata而不是其他分布式事务方案？**

**答：**

**对比其他方案：**

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **Seata** | 无侵入，性能好 | 依赖数据库事务 | 常规业务 |
| **RocketMQ事务消息** | 最终一致性 | 只支持RocketMQ | 异步场景 |
| **Saga** | 适合长流程 | 无隔离性 | 长事务 |
| **本地消息表** | 简单 | 代码侵入大 | 简单场景 |

**选择Seata的理由：**
1. **无侵入**：AT模式无需修改业务代码
2. **性能好**：一阶段提交本地事务，释放锁
3. **支持多种模式**：AT、TCC、Saga、XA
4. **社区活跃**：阿里开源，持续维护

**项目实例：**
- 医疗平台预约流程：Seata AT模式（简单）
- 电商平台订单流程：Seata TCC模式（性能）

**1. 缓存优化**
```java
// 多级缓存：本地缓存 + Redis
@Service
public class ProductService {
    
    // 本地缓存（Caffeine）
    private Cache<Long, Product> localCache = Caffeine.newBuilder()
        .maximumSize(10000)
        .expireAfterWrite(1, TimeUnit.MINUTES)
        .build();
    
    @Autowired
    private RedisTemplate<String, Product> redisTemplate;
    
    public Product getProduct(Long productId) {
        // 1. 查本地缓存
        Product product = localCache.getIfPresent(productId);
        if (product != null) {
            return product;
        }
        
        // 2. 查Redis
        String key = "product:" + productId;
        product = redisTemplate.opsForValue().get(key);
        if (product != null) {
            localCache.put(productId, product);
            return product;
        }
        
        // 3. 查数据库
        product = productMapper.selectById(productId);
        if (product != null) {
            redisTemplate.opsForValue().set(key, product, 1, TimeUnit.HOURS);
            localCache.put(productId, product);
        }
        
        return product;
    }
}
```

### 11. 遇到过哪些生产问题？

**面试官：你在项目中遇到过哪些生产问题？如何解决的？**

**答：**

**问题1：Redis内存突然飙升**

**现象：**
- Redis内存从50%飙升到90%
- 触发告警

**排查过程：**
```bash
# 1. 查看内存使用
INFO memory

# 2. 查找大key
redis-cli --bigkeys

# 3. 发现购物车数据异常
MEMORY USAGE cart:user:8888
# 5MB（正常用户100KB）
```

**问题原因：**
- 某个用户购物车添加了5万个商品
- 购物车未设置过期时间

**解决方案：**
```java
// 1. 限制购物车商品数量
public void addToCart(Long userId, Long productId, Integer count) {
    String key = "cart:user:" + userId;
    
    Long size = redisTemplate.opsForHash().size(key);
    if (size >= 100) {
        throw new BusinessException("购物车已满，最多100个商品");
    }
    
    redisTemplate.opsForHash().put(key, "product:" + productId, count);
    
    // 2. 设置过期时间
    redisTemplate.expire(key, 30, TimeUnit.DAYS);
}
```

**优化效果：**
- Redis内存稳定在50%

**问题2：数据库慢查询导致系统卡死**

**现象：**
- 数据库连接池耗尽
- 所有请求超时

**排查过程：**
```sql

-- 发现慢查询

WHERE DATE_FORMAT(appointment_date, '%Y-%m') = '2024-05';
```

**问题原因：**
- 使用函数导致索引失效
- 全表扫描100万行

**解决方案：**
```sql

SELECT * FROM t_appointment 
WHERE appointment_date >= '2024-05-01'

CREATE INDEX idx_appointment_date ON t_appointment(appointment_date);
```

**优化效果：**
- 查询RT：从30秒降到50ms
