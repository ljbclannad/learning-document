## 🎯 核心区别

**聊天消息 ≠ 会话上下文**

- **聊天消息** = 原始对话记录（完整历史）
- **会话上下文** = 提炼的关键信息（当前会话状态）

---

## 📊 对比分析

| 维度 | 聊天消息 | 会话上下文 |
|------|----------|-----------|
| 内容 | 完整对话记录 | 提炼的关键信息 |
| 数据量 | 大（几百条消息） | 小（几KB元数据） |
| 存储 | MySQL/MongoDB（持久化） | Redis（临时缓存） |
| 生命周期 | 永久保存 | 会话期间（1小时） |
| 用途 | 历史查询、审计 | AI上下文理解 |
| 更新频率 | 每条消息追加 | 定期提炼更新 |

## 1️⃣ 聊天消息（完整记录）
  
**存储位置：** MySQL `b_chat_message` 表

```sql
  CREATE TABLE b_chat_message (
      id BIGINT PRIMARY KEY,
      group_id VARCHAR(64),
      customer_id VARCHAR(64),
      sender_type VARCHAR(20),  -- 'user' / 'ai'
      content TEXT,
      message_type VARCHAR(20), -- 'text' / 'image' / 'file'
      create_time BIGINT,
      is_deleted TINYINT
  );
```

## 2️⃣ 会话上下文（提炼信息）

**存储位置：** Redis `ai:session:context:{groupId}`

```java
  public class SessionContext {

      // 当前会话状态
      private String currentTopic;              // 当前话题："运动方案"
      private String conversationPhase;         // 对话阶段："咨询中"

      // 关键信息提取
      private List<String> mentionedEntities;   // 提到的实体：["血糖", "运动", "饭后"]
      private Map<String, String> extractedData; // 提取的数据：{"血糖值": "7.2"}

      // 最近消息摘要（不是完整消息）
      private List<MessageSummary> recentSummaries; // 最近3-5条消息的摘要

      // 用户意图
      private String userIntent;                // 用户意图："咨询运动建议"
      private List<String> pendingQuestions;    // 待回答问题：["饭后多久运动"]

      // 会话元数据
      private Long sessionStartTime;            // 会话开始时间
      private Long lastUpdateTime;              // 最后更新时间
      private Integer messageCount;             // 消息计数

      // AI状态
      private String conversationId;            // AI对话ID（用于多轮对话）
      private Map<String, Object> aiState;      // AI内部状态
  }
```

- ❌ 不保存完整消息内容

---

## 🔄 两者的关系

**工作流程：**

```
用户发送消息
    ↓
1. 保存到MySQL（完整消息）
    ↓
2. 提取关键信息
    ↓
3. 更新Redis会话上下文
    ↓
4. AI读取会话上下文（不读完整消息）
    ↓
5. 生成回复
    ↓
6. 更新会话上下文
```

## 💻 代码实现

### 1. 会话上下文服务

```java
package com.sano.slmc.business.service.ai;

  import com.alibaba.fastjson.JSON;
  import lombok.Data;
  import lombok.extern.slf4j.Slf4j;
  import org.springframework.beans.factory.annotation.Autowired;
  import org.springframework.data.redis.core.StringRedisTemplate;
  import org.springframework.stereotype.Service;

  import java.time.Duration;
  import java.util.*;

  @Slf4j
  @Service
  public class SessionContextService {

      @Autowired
      private StringRedisTemplate redis;

      @Autowired
      private DeepSeekClient deepSeekClient;

      private static final String CONTEXT_KEY_PREFIX = "ai:session:context:";
      private static final Duration SESSION_TTL = Duration.ofHours(1);
      private static final int MAX_RECENT_SUMMARIES = 5; // 只保留最近5条摘要

      /**
       * 获取会话上下文
       */
      public SessionContext getContext(String groupId) {
          String key = CONTEXT_KEY_PREFIX + groupId;
          String json = redis.opsForValue().get(key);

          if (json == null) {
              log.debug("会话上下文不存在，创建新上下文: groupId={}", groupId);
              return createNewContext(groupId);
          }

          return JSON.parseObject(json, SessionContext.class);
      }

      /**
       * 更新会话上下文（用户发送消息后）
       */
      public void updateContextOnUserMessage(String groupId, String customerId, String message) {
          SessionContext context = getContext(groupId);

          // 1. 提取关键信息
          extractEntities(context, message);
          extractData(context, message);

          // 2. 识别用户意图
          String intent = identifyIntent(message);
          context.setUserIntent(intent);

          // 3. 添加消息摘要（不是完整消息）
          MessageSummary summary = new MessageSummary();
          summary.setRole("user");
          summary.setSummary(summarizeMessage(message)); // 提炼摘要
          summary.setTimestamp(System.currentTimeMillis());

          context.getRecentSummaries().add(summary);

          // 4. 保持最近N条摘要
          if (context.getRecentSummaries().size() > MAX_RECENT_SUMMARIES) {
              context.getRecentSummaries().remove(0);
          }

          // 5. 更新元数据
          context.setLastUpdateTime(System.currentTimeMillis());
          context.setMessageCount(context.getMessageCount() + 1);

          // 6. 保存到Redis
          saveContext(groupId, context);

          log.debug("更新会话上下文: groupId={}, intent={}", groupId, intent);
      }

      /**
       * 更新会话上下文（AI回复后）
       */
      public void updateContextOnAiReply(String groupId, String reply) {
          SessionContext context = getContext(groupId);

          // 1. 添加AI回复摘要
          MessageSummary summary = new MessageSummary();
          summary.setRole("ai");
          summary.setSummary(summarizeMessage(reply));
          summary.setTimestamp(System.currentTimeMillis());

          context.getRecentSummaries().add(summary);

          // 2. 保持最近N条摘要
          if (context.getRecentSummaries().size() > MAX_RECENT_SUMMARIES) {
              context.getRecentSummaries().remove(0);
          }

          // 3. 更新AI状态
          context.getAiState().put("last_reply_time", System.currentTimeMillis());

          // 4. 保存
          saveContext(groupId, context);
      }

      /**
       * 更新当前话题
       */
      public void updateTopic(String groupId, String topic) {
          SessionContext context = getContext(groupId);
          context.setCurrentTopic(topic);
          context.setLastUpdateTime(System.currentTimeMillis());
          saveContext(groupId, context);
      }

      /**
       * 清除会话上下文
       */
      public void clearContext(String groupId) {
          String key = CONTEXT_KEY_PREFIX + groupId;
          redis.delete(key);
          log.info("清除会话上下文: groupId={}", groupId);
      }

      /**
       * 保存会话上下文
       */
      private void saveContext(String groupId, SessionContext context) {
          String key = CONTEXT_KEY_PREFIX + groupId;
          String json = JSON.toJSONString(context);
          redis.opsForValue().set(key, json, SESSION_TTL);
      }

      /**
       * 创建新会话上下文
       */
      private SessionContext createNewContext(String groupId) {
          SessionContext context = new SessionContext();
          context.setSessionStartTime(System.currentTimeMillis());
          context.setLastUpdateTime(System.currentTimeMillis());
          context.setMessageCount(0);
          context.setRecentSummaries(new ArrayList<>());
          context.setMentionedEntities(new ArrayList<>());
          context.setExtractedData(new HashMap<>());
          context.setPendingQuestions(new ArrayList<>());
          context.setAiState(new HashMap<>());
          return context;
      }

      /**
       * 提取实体（使用DeepSeek NLP）
       */
      private void extractEntities(SessionContext context, String message) {
          try {
              String prompt = String.format(
                  "从以下健康相关消息中提取实体（如：血糖、血压、运动、饮食、药物、体重等），" +
                  "只返回JSON数组格式，例如：[\"血糖\", \"运动\"]。\n\n消息：%s", 
                  message
              );
              
              String response = deepSeekClient.chat(prompt);
              List<String> entities = JSON.parseArray(response, String.class);
              
              for (String entity : entities) {
                  if (!context.getMentionedEntities().contains(entity)) {
                      context.getMentionedEntities().add(entity);
                  }
              }
              
              log.debug("提取实体成功: {}", entities);
          } catch (Exception e) {
              log.error("DeepSeek提取实体失败，使用降级方案", e);
              // 降级方案：简单关键词匹配
              String[] keywords = {"血糖", "血压", "运动", "饮食", "药物", "体重"};
              for (String keyword : keywords) {
                  if (message.contains(keyword) && !context.getMentionedEntities().contains(keyword)) {
                      context.getMentionedEntities().add(keyword);
                  }
              }
          }
      }

      /**
       * 提取数据（使用DeepSeek NLP）
       */
      private void extractData(SessionContext context, String message) {
          try {
              String prompt = String.format(
                  "从以下健康消息中提取关键数据（如血糖值、体重、血压等），" +
                  "返回JSON对象格式，例如：{\"血糖值\": \"7.2\", \"体重\": \"65\"}。" +
                  "如果没有数据则返回空对象{}。\n\n消息：%s", 
                  message
              );
              
              String response = deepSeekClient.chat(prompt);
              Map<String, String> extractedData = JSON.parseObject(response, 
                  new TypeReference<Map<String, String>>() {});
              
              if (extractedData != null && !extractedData.isEmpty()) {
                  context.getExtractedData().putAll(extractedData);
                  log.debug("提取数据成功: {}", extractedData);
              }
          } catch (Exception e) {
              log.error("DeepSeek提取数据失败，使用降级方案", e);
              // 降级方案：正则匹配
              if (message.matches(".*血糖.*\\d+\\.?\\d*.*")) {
                  String value = message.replaceAll(".*血糖[^\\d]*(\\d+\\.?\\d*).*", "$1");
                  context.getExtractedData().put("血糖值", value);
              }
              if (message.matches(".*体重.*\\d+\\.?\\d*.*")) {
                  String value = message.replaceAll(".*体重[^\\d]*(\\d+\\.?\\d*).*", "$1");
                  context.getExtractedData().put("体重", value);
              }
          }
      }

      /**
       * 识别用户意图（使用DeepSeek NLP）
       */
      private String identifyIntent(String message) {
          try {
              String prompt = String.format(
                  "识别以下消息的用户意图，从以下选项中选择一个：" +
                  "\"咨询建议\"、\"报告数据\"、\"确认回复\"、\"一般对话\"。" +
                  "只返回意图文本，不要其他内容。\n\n消息：%s", 
                  message
              );
              
              String intent = deepSeekClient.chat(prompt).trim();
              log.debug("识别意图成功: {}", intent);
              return intent;
          } catch (Exception e) {
              log.error("DeepSeek识别意图失败，使用降级方案", e);
              // 降级方案：关键词匹配
              if (message.contains("怎么") || message.contains("如何") || message.contains("方案")) {
                  return "咨询建议";
              } else if (message.contains("血糖") || message.contains("血压") || message.contains("体重")) {
                  return "报告数据";
              } else if (message.contains("谢谢") || message.contains("好的")) {
                  return "确认回复";
              }
              return "一般对话";
          }
      }

      /**
       * 提炼消息摘要（使用DeepSeek NLP）
       */
      private String summarizeMessage(String message) {
          try {
              // 如果消息本身就很短，不需要摘要
              if (message.length() <= 50) {
                  return message;
              }
              
              String prompt = String.format(
                  "将以下消息提炼为30字以内的摘要，保留核心信息：\n\n%s", 
                  message
              );
              
              String summary = deepSeekClient.chat(prompt).trim();
              log.debug("生成摘要成功: {} -> {}", message, summary);
              return summary;
          } catch (Exception e) {
              log.error("DeepSeek生成摘要失败，使用降级方案", e);
              // 降级方案：截取前50字
              if (message.length() > 50) {
                  return message.substring(0, 50) + "...";
              }
              return message;
          }
      }
  }

  /**
   * 会话上下文数据结构
   */
  @Data
  class SessionContext {
      private String currentTopic;
      private String conversationPhase;
      private List<String> mentionedEntities;
      private Map<String, String> extractedData;
      private List<MessageSummary> recentSummaries;
      private String userIntent;
      private List<String> pendingQuestions;
      private Long sessionStartTime;
      private Long lastUpdateTime;
      private Integer messageCount;
      private String conversationId;
      private Map<String, Object> aiState;
  }

  /**
   * 消息摘要（不是完整消息）
   */
  @Data
  class MessageSummary {
      private String role;      // "user" / "ai"
      private String summary;   // 摘要内容
      private Long timestamp;   // 时间戳
  }
```

### 2. AI调用时的使用

```java
@Service
  public class AiChatService {

      @Autowired
      private SessionContextService contextService;

      @Autowired
      private UserProfileCacheService profileService;

      @Autowired
      private ChatMessageMapper messageMapper;

      /**
       * 处理用户消息
       */
      public void handleUserMessage(String groupId, String customerId, String message) {
          // 1. 保存完整消息到MySQL
          saveChatMessage(groupId, customerId, "user", message);

          // 2. 更新会话上下文（提炼关键信息）
          contextService.updateContextOnUserMessage(groupId, customerId, message);

          // 3. 获取用户画像
          UserProfile profile = profileService.getProfile(customerId);

          // 4. 获取会话上下文（不是完整消息）
          SessionContext context = contextService.getContext(groupId);

          // 5. 组装AI Prompt
          String prompt = buildPrompt(profile, context, message);

          // 6. 调用AI
          String reply = callAI(prompt);

          // 7. 保存AI回复到MySQL
          saveChatMessage(groupId, customerId, "ai", reply);

          // 8. 更新会话上下文
          contextService.updateContextOnAiReply(groupId, reply);
      }

      /**
       * 组装Prompt（使用上下文，不是完整消息）
       */
      private String buildPrompt(UserProfile profile, SessionContext context, String currentMessage) {
          StringBuilder prompt = new StringBuilder();

          // 用户画像
          prompt.append("用户信息：\n");
          prompt.append("- 年龄：").append(profile.getAge()).append("\n");
          prompt.append("- 健康目标：").append(String.join("、", profile.getHealthGoals())).append("\n");

          // 会话上下文
          prompt.append("\n当前话题：").append(context.getCurrentTopic()).append("\n");
          prompt.append("用户意图：").append(context.getUserIntent()).append("\n");

          // 提取的关键数据
          if (!context.getExtractedData().isEmpty()) {
              prompt.append("\n关键数据：\n");
              context.getExtractedData().forEach((k, v) ->
                  prompt.append("- ").append(k).append(": ").append(v).append("\n")
              );
          }

          // 最近对话摘要（不是完整消息）
          prompt.append("\n最近对话：\n");
          for (MessageSummary summary : context.getRecentSummaries()) {
              prompt.append(summary.getRole()).append(": ").append(summary.getSummary()).append("\n");
          }

          // 当前消息
          prompt.append("\n用户当前消息：").append(currentMessage).append("\n");

          return prompt.toString();
      }

      private void saveChatMessage(String groupId, String customerId, String senderType, String content) {
          // 保存到MySQL
          ChatMessage msg = new ChatMessage();
          msg.setGroupId(groupId);
          msg.setCustomerId(customerId);
          msg.setSenderType(senderType);
          msg.setContent(content);
          msg.setCreateTime(System.currentTimeMillis());
          messageMapper.insert(msg);
      }
  }
```

## 📊 数据流对比

**传统方式（读取完整消息）：**

```
AI调用
  ↓
查询MySQL最近100条消息（慢，几百KB）
  ↓
传给AI（Token消耗大）
```

**优化方式（使用会话上下文）：**

```
AI调用
  ↓
读取Redis会话上下文（快，几KB）
  ↓
传给AI（Token消耗小）
```

## 💡 总结

| 项目 | 聊天消息 | 会话上下文 |
|------|----------|-----------|
| 是什么 | 完整对话记录 | 提炼的关键信息 |
| 存哪里 | MySQL（持久化） | Redis（临时） |
| 数据量 | 大（几百条×几百字） | 小（几KB） |
| 用途 | 历史查询、审计 | AI实时理解 |
| 生命周期 | 永久 | 1小时 |
| 读取频率 | 低（查历史时） | 高（每次AI调用） |

**关键点：**
- ✅ 会话上下文 ≠ 聊天消息
- ✅ 会话上下文是提炼的元数据，不是完整消息
- ✅ AI调用时读上下文，不读完整消息历史
- ✅ 这样既快又省Token

### 2. DeepSeek Client 实现

```java
package com.sano.slmc.business.client;

import com.alibaba.fastjson.JSON;
import com.alibaba.fastjson.JSONObject;
import com.sano.slmc.business.config.DeepSeekConfig;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.*;
import org.springframework.stereotype.Component;
import org.springframework.web.client.RestTemplate;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

@Slf4j
@Component
public class DeepSeekClient {

    @Autowired
    private DeepSeekConfig config;

    @Autowired
    private RestTemplate restTemplate;

    /**
     * 调用DeepSeek API进行对话
     */
    public String chat(String prompt) {
        try {
            // 构建请求体
            Map<String, Object> requestBody = new HashMap<>();
            requestBody.put("model", config.getModel());
            requestBody.put("max_tokens", config.getMaxTokens());
            requestBody.put("temperature", config.getTemperature());
            
            // 构建消息列表
            List<Map<String, String>> messages = new ArrayList<>();
            Map<String, String> message = new HashMap<>();
            message.put("role", "user");
            message.put("content", prompt);
            messages.add(message);
            requestBody.put("messages", messages);

            // 设置请求头
            HttpHeaders headers = new HttpHeaders();
            headers.setContentType(MediaType.APPLICATION_JSON);
            headers.setBearerAuth(config.getApiKey());

            // 发送请求
            HttpEntity<String> entity = new HttpEntity<>(JSON.toJSONString(requestBody), headers);
            ResponseEntity<String> response = restTemplate.exchange(
                config.getApiUrl(),
                HttpMethod.POST,
                entity,
                String.class
            );

            // 解析响应
            if (response.getStatusCode() == HttpStatus.OK) {
                JSONObject jsonResponse = JSON.parseObject(response.getBody());
                String content = jsonResponse.getJSONArray("choices")
                    .getJSONObject(0)
                    .getJSONObject("message")
                    .getString("content");
                
                log.debug("DeepSeek API调用成功: prompt={}, response={}", 
                    prompt.substring(0, Math.min(50, prompt.length())), 
                    content.substring(0, Math.min(50, content.length())));
                
                return content;
            } else {
                log.error("DeepSeek API调用失败: status={}, body={}", 
                    response.getStatusCode(), response.getBody());
                throw new RuntimeException("DeepSeek API调用失败");
            }
        } catch (Exception e) {
            log.error("DeepSeek API调用异常: prompt={}", prompt, e);
            throw new RuntimeException("DeepSeek API调用异常", e);
        }
    }

    /**
     * 批量调用（用于提高效率）
     */
    public List<String> batchChat(List<String> prompts) {
        List<String> results = new ArrayList<>();
        for (String prompt : prompts) {
            try {
                results.add(chat(prompt));
            } catch (Exception e) {
                log.error("批量调用失败，跳过该prompt: {}", prompt, e);
                results.add(null);
            }
        }
        return results;
    }
}
```

### 5. 性能优化建议

**异步处理：**
```java
@Async
public CompletableFuture<String> chatAsync(String prompt) {
    return CompletableFuture.completedFuture(chat(prompt));
}
```

**缓存优化：**
```java
@Cacheable(value = "deepseek:nlp", key = "#prompt", unless = "#result == null")
public String chat(String prompt) {
    // ... 原有逻辑
}
```

**降级策略：**
- DeepSeek API 失败时，自动降级到简单的关键词匹配
- 设置超时时间，避免长时间等待
- 记录失败日志，便于监控和优化

**成本控制：**
- 对短消息（<20字）直接使用降级方案，不调用API
- 使用缓存减少重复调用
- 批量处理降低请求次数
