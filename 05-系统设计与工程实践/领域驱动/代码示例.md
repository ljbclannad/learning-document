# 数据对象
## 1. 实体
在订单系统中，通常会涉及多个实体，每个实体在系统中扮演着不同的角色。以下是一些常见的实体及其描述：

### 1. 用户（User）

- **描述**：表示系统中的用户，可能是顾客、管理员或其他角色。
- **属性**：
  - `userId`: 唯一标识符
  - `name`: 用户姓名
  - `email`: 用户邮箱
  - `password`: 用户密码（加密存储）
  - `address`: 用户地址

### 2. 产品（Product）

- **描述**：表示可供用户购买的商品。
- **属性**：
  - `productId`: 唯一标识符
  - `name`: 产品名称
  - `description`: 产品描述
  - `price`: 产品价格
  - `stock`: 当前库存数量

### 3. 订单（Order）

- **描述**：表示用户下的订单，包含订单的详细信息。
- **属性**：
  - `orderId`: 唯一标识符
  - `userId`: 下订单的用户 ID
  - `orderDate`: 订单日期
  - `status`: 订单状态（如待处理、已发货、已完成、已取消）
  - `totalAmount`: 订单总金额
  - `items`: 订单项列表（包含每个产品及其数量）

### 4. 订单项（OrderItem）

- **描述**：表示订单中的单个产品及其数量。
- **属性**：
  - `orderItemId`: 唯一标识符
  - `orderId`: 关联的订单 ID
  - `productId`: 关联的产品 ID
  - `quantity`: 购买数量
  - `price`: 购买时的单价

### 5. 支付（Payment）

- **描述**：表示与订单相关的支付信息。
- **属性**：
  - `paymentId`: 唯一标识符
  - `orderId`: 关联的订单 ID
  - `amount`: 支付金额
  - `paymentDate`: 支付日期
  - `status`: 支付状态（如已支付、待支付、支付失败）

### 6. 发货信息（ShippingInfo）

- **描述**：表示订单的发货细节。
- **属性**：
  - `shippingId`: 唯一标识符
  - `orderId`: 关联的订单 ID
  - `shippingAddress`: 发货地址
  - `shippingDate`: 发货日期
  - `trackingNumber`: 物流追踪号码
  - `carrier`: 承运商信息

### 7. 购物车（Cart）

- **描述**：表示用户在购物过程中选择的产品列表，通常在下单前管理。
- **属性**：
  - `cartId`: 唯一标识符
  - `userId`: 用户 ID
  - `items`: 购物车中的产品项（包含产品 ID 和数量）

### 8. 优惠券（Coupon）

- **描述**：表示可用于订单的优惠券信息。
- **属性**：
  - `couponId`: 唯一标识符
  - `code`: 优惠券代码
  - `discountAmount`: 折扣金额
  - `expirationDate`: 过期日期
  - `minimumPurchase`: 最低消费金额

### 9. 订单历史（OrderHistory）

- **描述**：记录用户的订单历史，跟踪用户的购买行为。
- **属性**：
  - `historyId`: 唯一标识符
  - `userId`: 用户 ID
  - `orderId`: 关联的订单 ID
  - `timestamp`: 记录时间
  - `action`: 用户操作（如下单、取消订单）

### 总结

这些实体构成了订单系统的核心部分，每个实体都负责特定的功能和数据管理。根据具体业务需求，可能还会有其他实体，但上述实体是大多数订单系统中常见和必要的组成部分。



## 2. 值对象

在订单系统中，值对象（Value Object）用于表示一些没有唯一标识的属性或数据结构，通常是不可变的。以下是几个常用的值对象示例：

### 1. Money（货币）

- **描述**：表示金额和货币类型。
- **属性**：
  - `amount`: 金额（通常是浮点数或整数）。
  - `currency`: 货币类型（如 USD、EUR）。

```java
public class Money {
    private final double amount;
    private final String currency;

    public Money(double amount, String currency) {
        this.amount = amount;
        this.currency = currency;
    }

    // Getters, equals, hashCode, toString
}
```

### 2. Address（地址）

- **描述**：表示用户的地址信息，通常用于发货或账单地址。
- **属性**：
  - `street`: 街道地址。
  - `city`: 城市。
  - `state`: 州/省。
  - `postalCode`: 邮政编码。
  - `country`: 国家。

```java
public class Address {
    private final String street;
    private final String city;
    private final String state;
    private final String postalCode;
    private final String country;

    public Address(String street, String city, String state, String postalCode, String country) {
        this.street = street;
        this.city = city;
        this.state = state;
        this.postalCode = postalCode;
        this.country = country;
    }

    // Getters, equals, hashCode, toString
}
```

### 3. OrderStatus（订单状态）

- **描述**：表示订单的状态，通常使用枚举来定义。
- **属性**：
  - `status`: 订单状态（如 PENDING、SHIPPED、COMPLETED、CANCELLED）。

```java
public enum OrderStatus {
    PENDING,
    SHIPPED,O
    COMPLETED,
    CANCELLED
}
```

### 4. Email（电子邮件）

- **描述**：表示用户的电子邮件地址。
- **属性**：
  - `email`: 电子邮件字符串。

```java
public class Email {
    private final String email;

    public Email(String email) {
        if (!isValid(email)) {
            throw new IllegalArgumentException("Invalid email address");
        }
        this.email = email;
    }

    private boolean isValid(String email) {
        // 验证电子邮件格式的逻辑
        return email.contains("@");
    }

    // Getters, equals, hashCode, toString
}
```

### 5. PhoneNumber（电话号码）

- **描述**：表示用户的电话号码。
- **属性**：
  - `number`: 电话号码字符串。

```java
public class PhoneNumber {
    private final String number;

    public PhoneNumber(String number) {
        this.number = number; // 可以添加验证逻辑
    }

    // Getters, equals, hashCode, toString
}
```

### 总结

这些值对象在订单系统中扮演着重要角色，帮助模块化和封装一些属性和逻辑。值对象的不可变性和均等性使得它们在领域模型中具有更高的可靠性和可维护性。通过合理地使用值对象，可以提高代码的清晰度和可读性。

## 3. 聚合根

在订单系统中，聚合根（Aggregate Root）是领域模型中重要的概念，负责管理与聚合内的实体和值对象的关系。以下是一些常用的聚合根示例：

### 1. 订单（Order）

- **描述**：代表用户下的订单，包含订单项和订单的相关信息。
- **属性**：
  - `orderId`: 唯一标识符
  - `userId`: 下单用户的 ID
  - `items`: 订单项列表（`OrderItem` 实体）
  - `status`: 订单状态（如待处理、已发货）
  - `totalAmount`: 订单总金额

```java
public class Order {
    private String orderId;
    private String userId;
    private List<OrderItem> items;
    private OrderStatus status;
    private Money totalAmount;

    // 构造函数和相关方法
}
```

### 2. 用户（User）

- **描述**：代表系统中的用户，可能是顾客、管理员等。
- **属性**：
  - `userId`: 唯一标识符
  - `name`: 用户姓名
  - `email`: 用户电子邮件（可作为值对象）
  - `orders`: 用户的订单列表

```java
public class User {
    private String userId;
    private String name;
    private Email email; // 使用值对象
    private List<Order> orders;

    // 构造函数和相关方法
}
```

### 3. 产品（Product）

- **描述**：代表可供购买的产品，包含产品的详细信息。
- **属性**：
  - `productId`: 唯一标识符
  - `name`: 产品名称
  - `description`: 产品描述
  - `price`: 产品价格
  - `stock`: 当前库存数量

```java
public class Product {
    private String productId;
    private String name;
    private String description;
    private Money price; // 使用值对象
    private int stock;

    // 构造函数和相关方法
}
```

### 4. 购物车（Cart）

- **描述**：代表用户购物时选择的产品集合，通常在下单前管理。
- **属性**：
  - `cartId`: 唯一标识符
  - `userId`: 关联用户的 ID
  - `items`: 购物车中的产品项（`CartItem` 实体）

```java
public class Cart {
    private String cartId;
    private String userId;
    private List<CartItem> items;

    // 构造函数和相关方法
}
```

### 5. 支付（Payment）

- **描述**：代表与订单相关的支付信息，处理支付的状态和方法。
- **属性**：
  - `paymentId`: 唯一标识符
  - `orderId`: 关联的订单 ID
  - `amount`: 支付金额
  - `status`: 支付状态（如已支付、待支付）

```java
public class Payment {
    private String paymentId;
    private String orderId;
    private Money amount; // 使用值对象
    private PaymentStatus status;

    // 构造函数和相关方法
}
```

### 总结

在订单系统中，这些聚合根各自管理相关的实体和值对象，并负责其生命周期和业务逻辑。通过清晰地定义聚合根，可以确保系统的可维护性和扩展性，同时遵循领域驱动设计的原则。这种结构使得业务逻辑更加集中，便于管理和理解。
