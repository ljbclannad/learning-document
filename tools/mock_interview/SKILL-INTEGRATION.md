# 面试 skill 的本地工具流程

本文件供 `learning-adaptive-mock-interview` 在工作区包含 `tools/mock-interview.py` 时读取。调用前阅读同目录 README 的输入输出约定及当前所需命令；具体字段以 README 和命令帮助为准。

## 选择记录方式

先用 `topic list` 和 `topic show` 查找当前主题。尚未初始化时，若没有该主题的既有 Markdown 记录，可执行 `init` 并创建主题。已存在的数据库主题始终使用工具记录；工具错误时保留待保存请求，修复后重试。

如果主题只存在旧 Markdown，先继续原文件记录流程。只有用户明确要求导入并完成预检核对后才切换到工具；遇到人工加权等阻断项保留原文件，不新建同名数据库主题冒充延续进度。

首次使用新主题时向用户说明数据库绝对路径与导出目录。首条回答前只保存主题、会话、考点及待答题元数据，不生成已评分记录或空白训练报告。

## 每题操作

1. 读取主题状态；未结束会话使用 `session resume`，保留其 ID。恢复后先处理当前题，再提示待核实事项。
2. 用 `next` 获取候选及理由。新考点先登记；同考点换问法沿用 ID。创建题目时提交当前会话版本，保存成功后才向用户提问。
3. 收到独立回答后用 `attempt append` 保存原文，摘要明确标记 `is_summary`。明确不会用 `cannot_answer`；它也支持在一次中性澄清提问后追加，保留首次回答时间和顺序，只计一次尝试。普通跳过走 `attempt skip`。
4. 需要澄清时分别保存 `clarification_question` 与 `clarification_answer`。提供实质提示前保存 `hint`；提示前没有回答的题按练习处理。已有首次回答后，提示引出的补充用 `supplement` 立即保存，无需等待评估；它不作为独立评分证据，也不新增作答次数。原题的初次回答仍用 `answer`。
5. 评估用 `attempt evaluate`，引用实际回答事件 ID。依据不足或存在版本争议时标记 `pending_verification`，暂不计分，练习题也适用。核实后用 `attempt revise`，带原评估版本和原因；独立尝试恢复为 `confirmed`，练习恢复为 `practice` 且等级为空。
6. 成功响应后使用工具返回的统计说明等级、权重变化；不要另外修改 Markdown 统计。讲解保存 `explanation`，修正复述保存 `correction`，跳过复述保存 `correction_skipped`。
7. 有实际回答后可独立导出 Markdown。数据库保存成功而导出失败时分别说明两个状态；失败后沿用原请求 ID 重试。只有导出成功才称文档已更新。

每次修改使用最新对象版本；同一写操作重试使用原请求 ID 和原完整请求。请求 ID 不同代表新的操作，不能用新 ID 重试不确定是否已经提交的回答。版本冲突先读取最新记录再决定是否修订。

## 分类纠正与规则调整

将提示误标为中性澄清，或将中性澄清误标为提示时，先读取 `attempt show` 的原始 `events` 和当前 `effective_events`，再调用 `attempt reclassify`。提供目标 `event_id`、新的 `event_type`（`hint` 或 `clarification_question`）、尝试版本和修订理由。已有评估时，同时提交 `evaluation_version` 及新的完整 `evaluation`，使分类、评分与统计在同一事务中更新；尚未评估时只修订分类，随后正常评估。

工具保留原事件，新增修订记录；不要直接修改 SQLite 或删除提示事件。答题前误标提示导致题目转为练习时，工具会依据所存的原题型恢复；旧事件缺少该信息时，核对来源后明确提供 `restore_kind`，不能猜测。原本就指定为练习的题不会自动升级为独立尝试。

用户调整评分规则时，先读取 `topic show`，通过 `rule create` 仅提交要求修改的参数；未提供参数继承当前生效规则。新版本不会改动旧题的规则快照，已排期的未来版本也不自动改写。需要恢复某项默认值时显式提交对应默认值。

## 暂停与总结

暂停用 `session pause`，保留待答题。结束用 `session end`；未答题不计失误，已回答待核实题保留为未决。根据 `report session` 和 `report weaknesses` 总结首次表现、复测和少数薄弱点，随后导出并给出绝对文件链接。

严格面试模式用 `feedback_mode=strict`。评估仍立即保存，讲解与等级展示延后至本轮结束。报告不是岗位胜任度测评，不将训练分数直接解释为高级岗位能力。

## 工具失败

保存失败时明确“尚未确认持久保存”，保留尝试 ID、请求 ID 和待保存输入；不要回退到另一份文件重复记账。读回或重试确认后再继续。第一版不支持任意人工调整权重，用户提出此要求时说明限制，保留其原始意图，不伪造等级来实现加权。
