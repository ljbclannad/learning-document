## 推荐阅读路径

### 入门路径

1. [Redis 主线知识笔记](Redis.md) 的“为什么快、I/O 多路复用、数据类型”。
2. [Redis 常见问答与复习清单](Redis-Q.md) 的基础与数据结构章节。
3. 按需阅读 [跳表详解](跳表详解.md) 和 I/O 多路复用比喻文档。

### 生产路径

1. 主线笔记中的持久化、高可用、缓存一致性与分布式锁。
2. [Redis Lua](RedisLua.md) 与 [Redis 生产高频专题](Redis生产高频专题.md)。
3. [Redis 在支付回调场景中的设计题](Redis场景题.md)，将机制组合到真实链路。

### 复习路径

1. 先按 [Redis-Q.md](Redis-Q.md) 的“30 秒答案”自测。
2. 不确定的原理回到主线笔记；Lua、跳表和生产边界进入相应专题。
3. 最后用支付场景题验证幂等、状态机、锁与缓存一致性是否能组合说明。
