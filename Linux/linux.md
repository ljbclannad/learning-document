# 1. 查看资源使用情况的常见命令
在 Linux 和 Unix 系统中，有多种命令可以用来查看系统的资源使用情况，包括 CPU、内存、磁盘和网络等。以下是一些常用的命令及其详细说明：

### 1. `top`

- **用途**：实时查看系统的进程和资源使用情况。
- **常用选项**：
  - `-u`：显示特定用户的进程。
  - `-p`：仅显示指定进程 ID 的信息。
- **输出内容**：包括 CPU 使用率、内存使用、交换空间、进程列表等。

### 2. `htop`

- **用途**：类似于 `top`，但提供更友好的用户界面和交互功能。
- **安装**：通常需要额外安装，使用 `sudo apt install htop` 或 `sudo yum install htop`。
- **特性**：可以使用键盘上下键选择进程，支持树状结构显示。

### 3. `free`

- **用途**：查看系统内存的使用情况。
- **常用选项**：
  - `-m`：以 MB 为单位显示。
  - `-g`：以 GB 为单位显示。
- **输出内容**：包括总内存、已用内存、空闲内存、缓存和交换空间。

### 4. `vmstat`

- **用途**：报告虚拟内存统计信息。
- **常用选项**：
  - `1`：每秒更新一次。
- **输出内容**：包括内存、交换、I/O、系统和 CPU 的使用情况。

### 5. `iostat`

- **用途**：查看 CPU 和 I/O 设备的使用情况。
- **常用选项**：
  - `-x`：显示扩展统计信息。
  - `1`：每秒更新一次。
- **输出内容**：包括每个设备的 I/O 使用率和等待时间。

### 6. `df`

- **用途**：查看文件系统的磁盘空间使用情况。
- **常用选项**：
  - `-h`：以人类可读的格式（如 GB）显示。
- **输出内容**：包括各个文件系统的总空间、已用空间、可用空间和挂载点。

### 7. `du`

- **用途**：查看目录或文件的磁盘使用情况。
- **常用选项**：
  - `-h`：以人类可读的格式显示。
  - `-s`：仅显示总计。
- **输出内容**：显示指定目录下每个文件或子目录的大小。

### 8. `netstat`

- **用途**：查看网络连接、路由表和网络接口统计信息。
- **常用选项**：
  - `-tuln`：显示所有监听的端口及连接。
  - `-i`：显示网络接口的统计信息。
- **输出内容**：包括网络连接、协议、状态和端口等信息。

### 9. `sar`

- **用途**：收集、报告和保存系统活动信息。
- **常用选项**：
  - `-u`：报告 CPU 使用情况。
  - `-r`：报告内存使用情况。
- **输出内容**：可以显示历史资源使用情况，适合长期监控。

### 10. `ps`

- **用途**：查看当前运行的进程。
- **常用选项**：
  - `aux`：显示所有用户的所有进程。
  - `-ef`：显示完整格式的进程信息。
- **输出内容**：包括进程 ID、CPU 和内存使用、状态、命令等。

### 总结

这些命令可以帮助用户监控和分析系统的资源使用情况。根据具体需求，可以选择合适的命令来获取所需信息。使用这些工具时，熟悉每个命令的选项和输出格式，可以更有效地管理和优化系统性能。

# 2. chmod
`chmod` 是 Linux 和 Unix 系统中用于改变文件或目录权限的命令。通过 `chmod`，用户可以设置谁可以读取、写入或执行文件。以下是关于 `chmod` 的详细说明：

### 1. 基本语法

```bash
chmod [选项]模式 文件名
```

### 2. 权限说明

每个文件和目录有三种基本权限：

- **读权限 (r)**：允许读取文件内容或列出目录内容。
- **写权限 (w)**：允许修改文件内容或在目录中添加、删除文件。
- **执行权限 (x)**：允许执行文件（如果是可执行文件）或进入目录。

### 3. 用户类别

权限可以分为三类用户：

- **用户 (u)**：文件的所有者。
- **组 (g)**：与文件所有者同组的用户。
- **其他 (o)**：系统中其他所有用户。

### 4. 权限模式

权限可以通过两种方式设置：符号模式和八进制模式。

#### 符号模式

- 使用 `u`、`g`、`o` 来表示用户类别。
- 使用 `+`、`-`、`=` 来添加、删除或设置权限。

**示例**：

```bash
chmod u+x file.txt  # 为文件所有者添加执行权限
chmod g-w file.txt  # 从组中删除写权限
chmod o=r file.txt  # 将其他用户的权限设置为只读
```

#### 八进制模式

- 权限用数字表示：
  - 读 (r) = 4
  - 写 (w) = 2
  - 执行 (x) = 1

- 将权限相加得到对应的数字。

**示例**：

```bash
chmod 755 file.txt  # 所有者有读、写、执行权限；组和其他用户有读、执行权限
chmod 644 file.txt  # 所有者有读、写权限；组和其他用户有读权限
```

### 5. 常用选项

- `-R`：递归地改变目录及其内容的权限。
- `-v`：显示详细信息，显示每个文件的权限更改。
- `-c`：仅在权限更改时显示信息。

### 6. 示例

1. **设置文件为可执行**：

   ```bash
   chmod +x script.sh
   ```

2. **递归更改目录权限**：

   ```bash
   chmod -R 755 /path/to/directory
   ```

3. **设置文件权限为 600（仅所有者可读写）**：

   ```bash
   chmod 600 secret.txt
   ```

### 7. 查看文件权限

使用 `ls -l` 命令可以查看文件的权限设置：

```bash
ls -l file.txt
```

输出示例：

```
-rwxr-xr-- 1 user group 1234 Jan 1 12:00 file.txt
```

- `rwxr-xr--` 表示文件的权限：所有者有读、写、执行权限；组有读、执行权限；其他用户有读权限。

### 总结

`chmod` 是一个强大的工具，用于控制文件和目录的访问权限。通过合理设置权限，可以增强系统的安全性。使用时需谨慎，以避免对文件或目录的错误权限设置。

# 3. 配置网络端口
在 Linux 系统中，配置网络端口通常涉及到网络接口的设置、服务的配置以及防火墙规则的调整。以下是一些常见的步骤和命令，用于配置网络端口。

### 1. 配置网络接口

#### 使用 `ip` 命令

- 查看网络接口：

  ```bash
  ip addr show
  ```

- 配置网络接口（例如，设置静态 IP 地址）：

  ```bash
  sudo ip addr add 192.168.1.100/24 dev eth0
  sudo ip link set eth0 up
  ```

#### 使用 `ifconfig` 命令（较旧）

- 查看网络接口：

  ```bash
  ifconfig
  ```

- 配置网络接口：

  ```bash
  sudo ifconfig eth0 192.168.1.100 netmask 255.255.255.0 up
  ```

### 2. 配置服务监听端口

- 对于大多数服务（如 `Apache`、`Nginx`、`MySQL` 等），其配置文件中通常会指定监听的端口。

- **示例**（以 `Apache` 为例）：

  编辑 `/etc/httpd/conf/httpd.conf` 或 `/etc/apache2/ports.conf`，设置监听端口：

  ```apache
  Listen 8080
  ```

- 重新启动服务：

  ```bash
  sudo systemctl restart httpd  # 对于 Apache
  ```

### 3. 防火墙配置

在 Linux 中，防火墙通常是通过 `iptables` 或 `firewalld` 配置的。

#### 使用 `iptables`

- 查看当前规则：

  ```bash
  sudo iptables -L -n
  ```

- 允许指定端口（例如，允许 8080 端口）：

  ```bash
  sudo iptables -A INPUT -p tcp --dport 8080 -j ACCEPT
  ```

- 保存规则：

  ```bash
  sudo iptables-save | sudo tee /etc/iptables/rules.v4
  ```

#### 使用 `firewalld`

- 启用和启动 `firewalld`：

  ```bash
  sudo systemctl start firewalld
  sudo systemctl enable firewalld
  ```

- 允许指定端口（例如，8080）：

  ```bash
  sudo firewall-cmd --zone=public --add-port=8080/tcp --permanent
  sudo firewall-cmd --reload
  ```

### 4. 验证端口是否开放

- 使用 `netstat` 或 `ss` 命令查看开放的端口：

  ```bash
  netstat -tuln  # 查看所有监听的端口
  ```

  或

  ```bash
  ss -tuln
  ```

- 使用 `telnet` 或 `nc` 命令测试端口：

  ```bash
  telnet localhost 8080
  ```

  或

  ```bash
  nc -zv localhost 8080
  ```

### 5. 示例：配置 HTTP 服务器

1. **安装 Apache**：

   ```bash
   sudo apt update
   sudo apt install apache2
   ```

2. **配置 Apache 监听 8080 端口**：

   编辑 `/etc/apache2/ports.conf`：

   ```apache
   Listen 8080
   ```

3. **启动 Apache**：

   ```bash
   sudo systemctl start apache2
   sudo systemctl enable apache2
   ```

4. **设置防火墙** 允许 8080 端口：

   ```bash
   sudo firewall-cmd --zone=public --add-port=8080/tcp --permanent
   sudo firewall-cmd --reload
   ```

5. **验证**：

   在浏览器中访问 `http://your-server-ip:8080`，检查服务是否正常工作。

### 总结

配置网络端口涉及多个步骤，包括网络接口的设置、服务的配置和防火墙的调整。确保在每个步骤中进行验证，以确保配置生效并且服务正常运行。


# 4. 文件系统层次
Linux 文件系统层次结构（Filesystem Hierarchy Standard，FHS）定义了 Linux 系统中文件和目录的标准组织方式。以下是 Linux 文件系统的主要目录及其用途：

### 1. 根目录 (`/`)

- 所有文件和目录的起始点。
- 其他所有目录都是从根目录派生的。

### 2. `/bin`

- 存放基本的用户命令和可执行文件，例如常用的 `ls`、`cp`、`mv` 等。
- 这些命令在系统启动时和单用户模式下可用。

### 3. `/sbin`

- 存放系统管理命令和可执行文件，通常由系统管理员使用。
- 包含如 `shutdown`、`ifconfig`、`fsck` 等命令。

### 4. `/etc`

- 存放系统配置文件和脚本。
- 包含用户账户信息、系统服务配置（如 `/etc/passwd`、`/etc/fstab`）。

### 5. `/dev`

- 设备文件的目录，表示计算机的硬件设备。
- 包含如 `/dev/sda`（硬盘）和 `/dev/tty`（终端设备）等。

### 6. `/proc`

- 虚拟文件系统，提供关于系统和进程的信息。
- 包含进程信息（如 `/proc/[pid]`）、系统信息和内核参数（如 `/proc/cpuinfo`）。

### 7. `/var`

- 存放可变数据文件，如日志文件、邮件、临时文件等。
- 包含 `/var/log`（日志文件）、`/var/mail`（邮件存储）。

### 8. `/tmp`

- 存放临时文件，系统重启后可以删除。
- 所有用户和程序均可使用这个目录。

### 9. `/usr`

- 存放用户程序和数据的目录，通常包含应用程序和库文件。
- 包含子目录：
  - `/usr/bin`：大部分用户命令。
  - `/usr/sbin`：系统管理命令。
  - `/usr/lib`：库文件。
  - `/usr/share`：共享数据文件。

### 10. `/home`

- 用户主目录，存放每个用户的个人文件和配置。
- 每个用户通常有一个以其用户名命名的子目录，如 `/home/alice`。

### 11. `/root`

- 超级用户（root）的主目录。
- 通常用于系统管理和维护。

### 12. `/media`

- 挂载可移动媒体（如 USB 驱动器和 CD-ROM）的目录。
- 系统自动挂载时，通常会在此创建子目录。

### 13. `/mnt`

- 临时挂载点，通常用于手动挂载文件系统。
- 系统管理员可以在此创建子目录以挂载其他文件系统。

### 14. `/opt`

- 存放附加软件包的目录，通常是第三方应用程序。
- 例如，安装的商业软件通常会放在此目录下。

### 总结

Linux 文件系统层次结构提供了一种组织和管理文件的标准方式，确保系统的可维护性和可扩展性。理解这些目录及其用途是有效使用 Linux 系统的基础。

# 5. netstat
`netstat` 是一个用于显示网络连接、路由表、接口统计信息和网络协议等信息的命令行工具。尽管在一些现代 Linux 发行版中，`netstat` 已被 `ss` 命令取代，但它仍然广泛使用。以下是关于 `netstat` 的详细说明和常用用法。

### 1. 基本语法

```bash
netstat [选项]
```

### 2. 常用选项

- `-a`：显示所有连接和监听端口。
- `-t`：仅显示 TCP 连接。
- `-u`：仅显示 UDP 连接。
- `-n`：以数字形式显示地址和端口号，而不是解析为域名。
- `-l`：仅显示正在监听的服务。
- `-p`：显示哪个进程正在使用该连接（需要 root 权限）。
- `-r`：显示路由表。
- `-i`：显示网络接口的情况。
- `-s`：显示网络统计信息。

### 3. 常见用法

#### 1. 查看所有活动连接

```bash
netstat -a
```

#### 2. 查看 TCP 连接

```bash
netstat -t
```

#### 3. 查看 UDP 连接

```bash
netstat -u
```

#### 4. 查看监听的端口

```bash
netstat -l
```

#### 5. 查看连接的进程

```bash
sudo netstat -p
```

#### 6. 查看路由表

```bash
netstat -r
```

#### 7. 查看网络接口的统计信息

```bash
netstat -i
```

#### 8. 查看网络统计信息

```bash
netstat -s
```

#### 9. 以数字格式查看连接

```bash
netstat -n
```

### 4. 示例输出解释

运行 `netstat -tuln` 命令可能会得到类似以下的输出：

```
Proto Recv-Q Send-Q Local Address           Foreign Address         State
tcp        0      0 0.0.0.0:80              0.0.0.0:*               LISTEN
tcp6       0      0 :::22                   :::*                    LISTEN
```

- **Proto**：协议类型（TCP、UDP）。
- **Recv-Q** 和 **Send-Q**：接收和发送队列的字节数。
- **Local Address**：本地地址和端口号。
- **Foreign Address**：远程地址和端口号。
- **State**：连接状态（如 LISTEN、ESTABLISHED）。

### 5. 注意事项

- 在许多现代系统中，建议使用 `ss` 命令，功能更强大且性能更高。例如，可以用 `ss -tuln` 来替代 `netstat -tuln`。
- 运行 `netstat` 可能需要 root 权限，尤其是查看进程信息时。

### 6. 总结

`netstat` 是一个强大的工具，用于监控和管理网络连接。通过合理使用其选项，可以帮助用户诊断网络问题和监控网络活动。

# 6. 查看管理进程
在 Linux 系统中，有多种命令可以用来查看和管理进程。以下是一些常用的命令及其详细说明：

### 1. `ps` 命令

`ps` 命令用于显示当前运行的进程。

#### 常用选项

- `-e`：显示所有进程。
- `-f`：以完整格式显示进程信息。
- `-u [用户名]`：显示指定用户的进程。

#### 示例

```bash
ps -ef         # 显示所有进程的完整信息
ps aux         # 显示所有用户的进程
```

### 2. `top` 命令

`top` 命令提供实时的进程监控。

#### 功能

- 显示当前系统的 CPU 和内存使用情况。
- 显示运行中的进程及其资源占用情况。

#### 操作

- 在命令行中输入 `top`，实时更新进程信息。
- 按 `q` 退出。

### 3. `htop` 命令

`htop` 是 `top` 的增强版本，提供了更友好的用户界面。

#### 安装

在某些系统上，可能需要安装：

```bash
sudo apt install htop   # Debian/Ubuntu 系统
sudo yum install htop   # CentOS/RHEL 系统
```

#### 使用

- 输入 `htop` 启动。
- 使用方向键选择进程，可以进行杀死进程、调整优先级等操作。

### 4. `pgrep` 命令

`pgrep` 用于根据名称或其他属性查找进程。

#### 示例

```bash
pgrep firefox       # 查找名为 firefox 的进程 ID
pgrep -u username   # 查找指定用户的所有进程
```

### 5. `kill` 命令

`kill` 命令用于终止进程。

#### 使用方法

```bash
kill [进程ID]          # 发送默认的 TERM 信号
kill -9 [进程ID]      # 强制终止进程（发送 KILL 信号）
```

### 6. `killall` 命令

`killall` 用于终止所有指定名称的进程。

#### 示例

```bash
killall firefox      # 终止所有名为 firefox 的进程
```

### 7. `nice` 和 `renice` 命令

- **`nice`**：以指定的优先级启动进程。
  
  ```bash
  nice -n 10 command   # 以优先级 10 启动命令
  ```

- **`renice`**：更改已运行进程的优先级。

  ```bash
  renice -n 15 -p [进程ID]  # 将指定进程的优先级更改为 15
  ```

### 8. `systemctl` 命令

用于管理系统服务和进程。

#### 常用操作

- 启动服务：

  ```bash
  sudo systemctl start service_name
  ```

- 停止服务：

  ```bash
  sudo systemctl stop service_name
  ```

- 查看服务状态：

  ```bash
  sudo systemctl status service_name
  ```

### 总结

这些命令提供了强大的功能来查看和管理 Linux 系统中的进程。根据需要，可以选择合适的命令进行进程监控、调整和管理。了解这些命令的使用方法是有效管理 Linux 系统的重要组成部分。
