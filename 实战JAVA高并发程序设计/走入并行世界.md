# 1. 你必须知道的几个概念

## 1.1 同步和异步

1. **同步**：同步方法调用一旦开始，调用方必须等到方法调用返回后，才能继续后续的行为。
2. **异步**：异步调用更像是一个消息传递，一旦开始，方法调用就会立即返回，调用者就可以继续后续的操作。而异步方法通常会在另外一个线程中“真实”地执行，整个过程中不会阻碍调用者的工作。

## 1.2 并发和并行

1. **并发**：侧重于多个任务交替执行。而多个任务之间可能还是串行的。
2. **并行**：真正意义上的同时执行。

## 1.3 临界区

1. 临界区用来表示一种公共资源或者共享资源，可以被多个线程使用，但是每一次只能有一个线程使用它，一旦临界区资源被占用，其他线程要想使用这个资源就必须等待。
2. 在并行程序中，临界区资源是保护的对象，如果意外出现两个线程同时执行资源的情况，程序并不能获取到想要的结果。

## 1.4 阻塞（Blocking）和非阻塞(Non-Blocking)

1. **阻塞**：一个线程占用了临界区资源，那么其他所有需要这个资源的线程就必须在这个临界区等待。等待会导致线程挂起，这种情况就是阻塞。如果此时占用的线程一直不愿意释放资源，那么其他所有阻塞在这个临界区的线程都不能工作。
2. **非阻塞**：它强调没有一个线程可以妨碍其他线程执行，所有的线程都会尝试不断的执行。

## 1.5 死锁（Deadlock），饥饿（Stravation）和活锁（LiveLock）

1. **死锁**：彼此互相占用了资源，需要满足以下4个条件
   1. **互斥条件**：任务使用的资源中至少有一个是不能共享的，资源的使用和释放方法都使用了synchronized关键字修饰
   2. **请求与保持条件**：至少有一个任务它必须持有一个资源并且这个任务正在等待获取另一个当前正在被别的任务持有的资源
   3. **不可剥夺条件**：资源不能被项目抢占，任务必须把资源释放当做普通事件，资源只能被释放后才能被其他任务获取到
   4. **循环等待条件**：必须有循环等待，这时一个任务等待其他任务释放资源，其他任务又在等待另一个任务释放资源，且直到最后有一个任务在等待第一个任务释放资源，使得大家都被锁住，就造成了死锁
2. **饥饿**：某一个或者多个线程因为种种原因无法获得所需要的资源，导致一直无法执行。
   1. 线程池优先级太低，而高优先级的线程不断抢占它需要的资源，导致低优先级线程无法工作。
   2. 一直无法获取到想要的资源（资源被其他线程占用），也是属于饥饿的一种可能。
3. **活锁**：线程主动将资源释放给他人使用，那么就会导致资源不断地在两个线程之间跳动，而没有一个线程可以同时拿到所有资源正常执行。



# 2.并发级别

1. **阻塞**：一个线程是阻塞的，那么在其他线程释放资源之前，当前线程无法继续执行，当我们使用synchronized关键字或者重入锁时，我们得到的线程就是阻塞的线程。
2. **无饥饿**：线程调用满足公平锁，按照先来后来的规则，不管新来的线程优先级多高，要想获得资源，就必须乖乖排队。
3. **无障碍**：两个线程可以同时进入临界区，对于无障碍的线程来说，一旦检测到这种情况，它就会立即对自己所做的修改进行回滚，确保数据安全。但如果没有数据竞争发生，那么线程就可以顺利完成自己的工作，走出临界区。
4. **无锁**：在无锁的情况下，所有的线程都能尝试对临界区进行访问，但不同的是，无锁的并发保证必然有一个线程能够在有限步内完成操作离开临界区。
5. **无等待**：无锁只要求有一个线程可以在有限步内完成操作，而无等待则要求所有的线程都必须要有限步内完成，这样就不会引起饥饿问题。



# 3. JMM

1. **原子性**：原子性是指一个操作是不可中断的。即使是在多个线程一起执行的时候，一个操作一旦开始就不会被其他线程干扰。
2. **可见性**：当一个线程修改了某一个共享变量的值时，其他线程是否能够立即知道这个修改。
3. **有序性**：指令重排。
