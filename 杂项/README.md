# 杂项

收集后端学习主线之外，出于好奇而了解的技术、工具和互联网服务。先弄懂它是什么、有什么用、边界在哪里，不要求每篇都深入到源码或生产实践。

## 笔记入口

- [[杂项/Cloudflare入门|Cloudflare 入门]]：从 Nginx 前面的边缘代理，认识 CDN、安全防护、Workers 和 Tunnel。
- [[杂项/DeepSeek Super-agent入门|DeepSeek Super-agent 入门]]：认识事件驱动 Agent 的授权、工单、并发调度、持久化与恢复边界。

## 维护方式

- 一项主题一篇笔记，文件名直接使用主题名；新增后在这里补一条链接和一句说明。
- 先平铺存放，同类内容积累较多后再建子目录，不提前拆出大量空分类。
- 优先记录自己的理解和官方来源；涉及套餐、限制、操作步骤时注明核对日期。
- 与已有后端专题重叠时链接到原笔记；若以后深入为正式部署实践，再考虑归入对应专题。
