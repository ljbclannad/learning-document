## 验证层次与覆盖

[后处理状态实验.py](./后处理状态实验.py) 是原正文中 postprocess_state_lab.py 代码块的独立文件。5 个 unittest 用例覆盖：预标记导致丢工作、部分完成后恢复、ACK 丢失后重复、同键异参冲突以及新任务身份。

## 运行与环境

使用 Python 3.10+ 标准库，在仓库根目录执行：

```sh
python3 '07-项目复盘与方案/智能体重管理/AI对话系统/实验/后处理状态实验.py'
```

脚本只修改单进程内存集合，无磁盘、网络、模型或数据库调用。成功时 unittest 报告 5 项通过。

## 验证边界与相邻实验

集合去重代表假定的资源端幂等效果，不代表完成了数据库事务、RabbitMQ 重投、租约或外部结果不明验证。患者轮次排序、审批、取消与旧结果拒绝，见 [统一状态契约实验说明](../../医生助手Agent/实验/README.md)。Outbox 与持久恢复见 [[07-项目复盘与方案/通用系统方案/实验/README|可靠执行实验说明]]。
