## 验证层次与覆盖

[统一状态契约实验.py](./统一状态契约实验.py) 是单进程内存状态模型，包含 23 个 unittest 用例。按轮次排队、请求身份、审批绑定、外部结果不明、取消、租约和摘要版本分组阅读；其中故意保留了旧文本解析器的误判反例。

## 运行与环境

使用 Python 3.10+ 标准库，在仓库根目录执行：

```sh
python3 '07-项目复盘与方案/智能体重管理/医生助手Agent/实验/统一状态契约实验.py'
```

只操作内存，无模型请求、数据库连接、真实患者数据或外部发送。成功时 unittest 报告 23 项通过。

## 验证边界与相邻实验

内存方法代表设计中的条件检查与状态迁移，不证明 MySQL 并发原子性、真实 HTTP 回执、部署恢复或临床质量。更小的目标/证据版本模型与本地持久动作实验见 [[06-AI应用后端/02-Agent与RAG/实验/README|Agent 基础实验说明]]；它们是分层学习材料，不能把测试总数当作完整系统验收结果。
