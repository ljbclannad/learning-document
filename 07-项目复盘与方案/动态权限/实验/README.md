## 验证层次与覆盖

[权限覆盖与快照实验.py](./权限覆盖与快照实验.py) 是从正文原样提取的单进程内存模型：18 条 assert 检查继承与显式空覆盖、功能门控、机构/科室边界、账号停用、旧快照回填及乱序通知。正文保留规则解释与真实集成要求，完整源码只在这里维护。

## 运行与环境

使用 Python 3.10+ 标准库，在仓库根目录执行：

```sh
python3 '07-项目复盘与方案/动态权限/实验/权限覆盖与快照实验.py'
```

正常通过没有输出，退出码为 0；断言失败会报错。不要加 `-O`，也不要设置 `PYTHONOPTIMIZE`，否则 assert 可能被关闭。脚本只操作内存，不连接数据库或 Redis，不修改真实权限。

## 验证边界

快照检查与发布被视为不可分的串行操作，且假定权威版本已可靠发布；这不证明真实缓存原子性或严格撤权。需要理解授权与写入排序时，继续阅读 [共享可靠执行实验说明](../../通用系统方案/实验/README.md)，不要把两种模型的保证混用。
