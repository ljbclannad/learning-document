## 运行与环境

使用 Python 3.10+ 标准库。在仓库根目录执行需要的脚本：

```sh
python3 '07-项目复盘与方案/通用系统方案/实验/支付幂等与事务实验.py'
python3 '07-项目复盘与方案/通用系统方案/实验/租约与旧执行者实验.py'
python3 '07-项目复盘与方案/通用系统方案/实验/可靠执行边界实验.py'
```

支付实验仅使用内存数据库，租约实验只使用内存对象。可靠执行边界实验在系统临时目录创建 SQLite 文件并打印路径，**运行后保留文件供检查**；本次整理不改变这一行为。所有脚本不连接 RabbitMQ、Redis、MySQL 或支付渠道。

## 验证边界

测试中的预期错误是学习对象：“旧 worker 被放行”与“外部产生两次效果”的反例测试通过，表示错误被成功复现，不表示真实副作用已经解决。SQLite 写事务也不能代替 MySQL 行锁与隔离级别验证；confirm/return 只是输入事件模型，没有真实 broker。

## 本次验证

2026-10-29，Python 3.12.9：6 个支付测试、3 个租约测试与 16 个可靠执行测试通过。涉及 SQLite 的本机版本为 3.51.3；上述验证范围与限制仍然适用。
